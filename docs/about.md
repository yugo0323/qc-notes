# このサイトについて

QCLab は、量子化学を入門から最先端まで学ぶための個人のノートです。
毎朝の論文紹介と、連載の講義ノートを載せています。

## 論文紹介の作り方

- 毎朝、arXiv、ChemRxiv、主な雑誌（Crossref に登録された情報）から新しい論文を集め、電子構造理論・遷移金属錯体の計算・量子化学のための機械学習に関係の深いものを選びます。
- 紹介文は、AI アシスタント（Claude）が論文の要旨や本文を読んで**自動で書き、人による確認を経ずに公開**しています。
- 公開の前に、次のことを機械的に確かめています。
    - 紹介した論文が実在し、題名が一致すること（Crossref または arXiv に問い合わせる）。
    - 紹介した論文以外の文献を引用していないこと。
    - 決まった見出しと注意書きがあること。
- それでも誤りが含まれることがあります。**正確な内容は、必ず原論文で確認してください。**

## 講義ノートの作り方

- 下書きは AI アシスタント（Claude）と一緒に作り、筆者が読んで確認してから載せています。

## 正確さのルール

- 紹介する論文は、題名・著者・雑誌・年・DOI を確かめたものだけを載せます。
- 論文紹介には、「要旨だけを読んで書いた」のか「本文まで読んだ」のかを書きます。
- 論文に書いてあることと、意見・推測は分けて書きます。
- 論文の図は載せません（講義ノートでは、再利用が許されたライセンスのものだけを出典付きで使います）。

## 誤りを見つけたら

GitHub の [Issue](https://github.com/yugo0323/qc-notes/issues) で教えていただけると助かります。
