# このサイトについて

量子化学を学ぶための個人のノートです。

## 作り方

- 文章の下書きは、AI アシスタント（Claude）と一緒に作り、筆者が読んで確認してから載せています。
- 誤りに気づいたら、GitHub の Issue で教えていただけると助かります。

## 正確さのルール

- 紹介する論文は、題名・著者・雑誌・年・DOI を確かめたものだけを載せます。
- 論文紹介には、「要旨だけを読んで書いた」のか「本文まで読んだ」のかを書きます。
- 論文に書いてあることと、筆者の意見・推測は分けて書きます。
- 論文の図は、CC-BY などの再利用が許されたライセンスのものだけを、出典を付けて載せます。
