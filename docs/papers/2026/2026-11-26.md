## 3 行でいうと

1. 通常の TDDFT（断熱近似）は、二重励起の性格をもつ状態を扱えません。Dressed TDDFT（DTDDFT）は、周波数依存の補正でこれを補います。
2. この論文は、DTDDFT を「ブラックボックス」に近づけるため、補正が要るかどうかの判定手順、反復の曖昧さを消す線形化（undownfolding）、動的相関の補正を提案しています。
3. 結果は、汎関数・変種・TDA の有無に強く依存します。ポリエンの 2Ag 状態などで改善する例がある一方、虚数の周波数が出る場合や、補正で悪化する場合も報告されています。

## 背景：何が問題だったか

TDDFT の断熱近似では、交換相関カーネルが周波数に依存しません。このため、Kohn–Sham（KS）の一電子励起どうししか混ざらず、二重励起の性格をもつ状態（ポリエンの暗い 2Ag 状態など）が出ません。論文はこれを出発点にしています。

DTDDFT は、この欠点を直す既存の方法です。ただし論文は、これが「ブラックボックスにはほど遠い」と述べ、運用上の問題を整理しています。

## 何をしたか

- **DTDDFT の骨組み**：関係する KS 一電子励起 $N_q$ 個と、KS の二重励起 1 個を含む小さな空間で、周波数依存の項を行列に足します。周波数に依存するので、反復して解く必要があります。
- **変種**：分母に KS の励起周波数を使う s 型と、断熱 TDDFT の周波数を使う a 型があります。論文では a 型のほうが良い結果でした。Tamm–Dancoff 近似（TDA）版も扱っています。TDA 版は振動子強度が信頼しにくく、和則も満たさないと述べています。
- **補正が要るかの判定手順**：最低の KS 二重励起（たとえば HOMO²→LUMO²）と同じ対称性の断熱 TDDFT 状態を候補にします。KS 一電子励起は、寄与が 10% 以上のもの、半数を超える根に寄与するもの、二重励起との結合が大きいものを取ります。基準値は利用者が決める閾値で、経験的に選んだと述べています。
- **undownfolding**：周波数依存の行列を、次元 $N_q+1$ の線形・エルミートの行列に置き換えます。1 回の対角化で全状態が得られ、「どの根を反復するか」の曖昧さがなくなります。同値になる条件も論文で議論されています。
- **動的相関の補正（$\Delta c$）**：小さな空間に切り詰めると、空間の外の状態にかかる動的相関が落ちます。その分を、断熱 TDDFT の「全空間」と「切り詰め」の差で補います。

## 結果

参照には QUESTDB、Δ-CR-EOMCC(2,3)、CC3 の一電子励起性格の指標（%T1）などを使っています。計算は NWChem、PBE・PBE0・CAM-B3LYP、主に cc-pVDZ です。

- **ブタジエン、ヘキサトリエン**：参照では 1Bu と 2Ag が交差します。CAM-B3LYP の断熱 TDDFT は 2Ag を約 2 eV 過大評価し、交差が出ません。DTDDFT では交差が現れ、a 型は s 型より参照に近くなりました。
- **汎関数依存**：補正の効果は PBE で最大、CAM-B3LYP で最小です。PBE では DTDDFT の性能が悪く、虚数の周波数も出ます。
- **虚数の周波数**：ヘキサトリエンの PBE0 で、結合交替（BLA）が小さい側で s 型に虚数の周波数が出ます。三重項不安定性に似た現象と論文は述べています。TDA 版では見られませんでした。
- **オクタテトラエン**：参照（CASPT3）の 2Ag は 4.680 eV です。CAM-B3LYP の a 型は 4.7 eV 付近と、近い値でした（表が読み取りにくく、概数です）。
- **シクロペンタジエン**：CAM-B3LYP の $\Delta c$ 付き a 型で、二重励起の 2A1 の誤差が、断熱 TDDFT による一電子励起の 1B1 の誤差より小さいと報告されています。
- **アクロレイン**：切り詰めの影響が支配的で、$\Delta c$ は CAM-B3LYP と PBE0 でエネルギーを悪化させました。「入れ子」の余分な A′ 状態も現れ、意味は今後の課題とされています。
- **ナフタレン**：PBE と PBE0 では、2Ag と 3Ag の順序が入れ替わります。以降の結果は読めていません。
