## 3 行でいうと

1. 一重項対だけの結合クラスター法（CCSD0）に、F12 理論（電子間距離を陽に含める理論）を組み合わせた CCSD0-F12Pi と、その摂動論的トリプルス版を提案しています。
2. 正則化で落ちる三重項（同スピン）対の相関を、カスプ条件を満たす「擬似励起演算子」で補います。
3. N₂ と CO₂ の結合解離などで、通常の CCSD(T) に出る不自然なこぶや振動を避け、基底関数の収束も速くなると報告しています。

## 背景：何が問題だったか

結合の切断のように静的相関が強い場面では、単一参照の CCSD(T) は不自然な曲線を出すことがあります。多参照の結合クラスター法は活性空間の選択が必要で、費用も大きくなります。

CCSD0 は、二電子励起を一重項対（逆スピン対）に限る方法です。本文は、この制限で同スピンの動的相関が失われると述べています。一方、F12 法は、電子間のカスプ（二電子が近づく点での波動関数の折れ）を扱い、基底関数の収束を速めます。F12 を CCSD0 と組み合わせるとき、落ちた三重項の相関をどう戻すかが課題になります。

## 何をしたか

- 一重項は通常の F12 項で扱います。
- 正則化で落ちた三重項の相関は、新しい擬似励起演算子（本文の Pi の項）で回収します。この演算子はカスプ条件を満たし、仮想空間の全体を使います。
- 本文は、CCSD0 が「複素分子軌道」の枠組みと構造上つながると示しています。この枠組みは、虚数のスピン一重項不安定性があるとき、RHF より低いエネルギーを与えます。
- 計算量は CCSD と同じ $O(N^6)$ で、活性空間の選択は要りません。
- 実装は DIRCCR12-OS を改造したもので、凍結内殻近似と標準近似（SA）を使っています。基底関数は cc-pVXZ です。

## 結果

| 系 | 内容 | 本文に書かれた結果 |
|---|---|---|
| N₂ | 解離曲線、分光定数（cc-pVTZ、cc-pV5Z） | 5Z の $D_0$ は 227.23 kcal/mol で、実験の 225.36 に対し、TZ の 230.90 より近い。(T) 版の $D_e$ は実験より大きい |
| CO₂ | 対称伸縮の解離曲線 | CCSD(T) は 3.5〜5.5 a₀ に落ち込みとこぶ。CCSD(T)-F12 は振動。CCSD0(T)-F12Pi は滑らかで単調 |
| CH₂（直線、一重項） | cc-pVDZ〜5Z の全エネルギー | CCSD0-F12Pi/DZ（−38.991582 Eh）は CCSD0/5Z（−38.990794 Eh）より低い |
| シクロブタジエン遷移状態 | cc-pVDZ〜QZ | F12Pi/DZ は CCSD0/QZ より低い。ただし DZ より大きい基底では、Mukherjee の多参照 CC（Mk-CC）の値より高いまま |

著者は、(T) には同スピンの成分がなく、収束が doubles より遅いと述べています。N₂ の $D_e$ の過大評価も、これに結びつけています。
