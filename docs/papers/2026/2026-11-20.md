## 3 行でいうと

1. 遷移金属錯体の HOMO・LUMO のエネルギーを機械学習で予測するとき、安価な半経験的計算で得た軌道の原子ごとの寄与を「重み」として使う方法（軌道重み付き学習）を提案しています。
2. 遷移金属錯体のデータセットで、必要な訓練データを最大 95% 減らせたと報告しています。
3. 一方、QM9 のような小さな有機分子では、多くの表現でむしろ悪くなりました。軌道が局在する大きな分子向けの方法です。

## 背景：何が問題だったか

HOMO と LUMO（最高占有・最低非占有分子軌道）のエネルギーは、分子が光とどう相互作用するかを決めます。遷移金属錯体では、この差（ギャップ）が可視光の範囲に入ります。

遷移金属錯体は、電荷とスピン状態の種類が多く、予測が難しい対象です。幾何構造だけから作った原子環境の表現は、そのままでは電荷やスピンを区別しません。

## 何をしたか

- **重みの作り方**：GFN2-xTB（半経験的な計算法。開殻系にはスピン分極版）で 1 回計算し、各分子軌道について、各原子が持つ Mulliken 型の寄与（占有の割合）を求めます。
- **使い方**：原子ごとの局所的な表現を足し合わせて分子全体の表現を作る際に、この寄与を重みとして掛けます。単純な和は、重みをすべて 1 にした場合にあたります。1 回の xTB 計算で、すべての軌道の重みが得られます。
- **電荷とスピンの補正**：電荷とスピン状態をワンホット符号化して最小二乗で当てはめ、その分をラベルから引いてから学習します。
- **学習器**：ガウスカーネルのカーネルリッジ回帰です。
- **表現**：物理に基づく FCHL19 と cMBDF、事前学習済みの MACE モデル 3 種（MACE-OFF、MACE-MP0、MACE-OMol）を試しています。
- **目的変数**：HOMO、LUMO、ギャップ。直接学習と、xTB の値との差を学習する Δ 学習の両方を調べています。
- **データ**：tmPHOTO（tmQM の部分集合）、TM-GSspin+、QM9 です。

## 結果

- **tmPHOTO の HOMO**：FCHL19 と cMBDF は、重みなしで 3,414 点で達する精度に、重み付きなら 128 点で達します（95% 減）。HOMO の誤差は MACE-OMol が最小でした。
- **tmPHOTO のギャップ**：FCHL19 で必要なデータが 75% 減りました。
- **TM-GSspin+**：誤差の減少は最大で FCHL19 が 70%、MACE-MP0 が 74%、cMBDF が 59% です。
- **QM9**：FCHL19 は LUMO で 33%、ギャップで 19% 改善しました。一方、MACE-OFF はすべての性質で悪化し、cMBDF の HOMO も 23% 悪化しました。
- **費用（500 分子、CPU 1 コア、tmPHOTO）**：MACE-OMol が 2,163 秒、FCHL19 が 14 秒、xTB の一点計算が追加で 406 秒でした。要旨は、物理ベースの表現が事前学習済みニューラルネットワーク表現にほぼ並ぶ精度を、推論費用の 12% で得ると述べています。
