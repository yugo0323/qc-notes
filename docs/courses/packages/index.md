# 計算パッケージの使い方

量子化学計算のプログラムの使い方を、入力ファイルの書き方から結果の読み方まで学びます。
商用のプログラムは、各社のライセンス条件の範囲で、一般的な使い方だけを扱います。

| 回 | 題 | 目安 |
|---|---|---|
| 1 | 計算の流れ：構造を作る、計算する、結果を読む | 入門 |
| 2 | 分子構造の作り方と可視化 | 入門 |
| 3 | どのプログラムにも共通すること：電荷、スピン多重度、基底関数、計算方法 | 入門 |
| 4 | Gaussian（1）：入力ファイルと構造最適化 | 基礎 |
| 5 | Gaussian（2）：振動解析、熱化学、溶媒効果 | 基礎 |
| 6 | ORCA（1）：入力ファイルと構造最適化 | 基礎 |
| 7 | ORCA（2）：振動解析と熱化学 | 基礎 |
| 8 | ORCA（3）：DLPNO-CCSD(T) と CASSCF/NEVPT2 | 発展 |
| 9 | GAMESS（1）：入力ファイルの書き方 | 基礎 |
| 10 | GAMESS（2）：MRSF-TDDFT で励起状態を計算する | 発展 |
| 11 | PySCF（1）：Python から量子化学計算をする | 基礎 |
| 12 | PySCF（2）：積分、Fock 行列、密度行列を見る | 基礎 |
| 13 | xtb と CREST：速い半経験的計算と配座探索 | 基礎 |
| 14 | ASE：計算を Python でつなぐ | 基礎 |
| 15 | 機械学習ポテンシャルを動かす | 発展 |
| 16 | 計算がうまくいかないとき：SCF の収束、虚振動、スピン状態 | 発展 |
