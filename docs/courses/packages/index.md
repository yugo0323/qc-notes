# 計算パッケージの使い方

量子化学計算のプログラムの使い方を、入力ファイルの書き方から結果の読み方まで学びます。
（予定の目次です。商用プログラムは、各社のライセンス条件の範囲で、一般的な使い方だけを扱います。）

| 回 | 題 | 目安 |
|---|---|---|
| 1 | 計算の流れ：構造を作る、計算する、結果を読む | 入門 |
| 2 | 分子構造の作り方と可視化 | 入門 |
| 3 | PySCF：Python から量子化学計算をする | 基礎 |
| 4 | PySCF で中身を見る：積分、Fock 行列、密度行列 | 基礎 |
| 5 | ORCA：入力ファイルと構造最適化 | 基礎 |
| 6 | ORCA：振動解析と熱化学 | 基礎 |
| 7 | ORCA：DLPNO-CCSD(T) と CASSCF/NEVPT2 | 発展 |
| 8 | xtb と CREST：速い半経験的計算と配座探索 | 基礎 |
| 9 | ASE：計算を Python でつなぐ | 基礎 |
| 10 | 機械学習ポテンシャルを動かす | 発展 |
| 11 | 計算がうまくいかないとき：SCF の収束、虚振動 | 発展 |
