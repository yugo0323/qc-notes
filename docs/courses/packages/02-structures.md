## 1. xyz 形式：直交座標で書く

最も広く使われる形式は、xyz 形式です。
各原子の位置を、直交座標 $(x, y, z)$ で書きます。
単位はオングストローム（Å、$10^{-10}$ m）です。
水分子の例を示します。

```text
3
water, rough guess
O    0.000000    0.000000    0.117300
H    0.000000    0.757200   -0.469200
H    0.000000   -0.757200   -0.469200
```

決まりは三つだけです。

1. 1 行目は原子の数です。
2. 2 行目は注釈の行です。何を書いても構いませんが、空でも 1 行は必要です。
3. 3 行目からは、1 行に 1 原子ずつ、元素記号と $x$、$y$、$z$ を並べます。

xyz 形式には、電荷やスピン多重度、原子どうしの結合の情報は入りません。
電荷と多重度は、計算プログラムの入力で別に指定します（第 3 回）。
結合は、可視化ソフトが原子間の距離から推測して描きます。

多くの計算プログラムは、xyz 形式の座標部分（3 行目以降）をそのまま入力に貼り付けて使えます。
そのため、xyz 形式は、プログラムの間で構造を受け渡すときの共通の形式になっています。

**ここまでで分かったこと**：xyz 形式は「原子数、注釈、元素記号と座標（Å）」だけの単純な形式で、プログラムの間の受け渡しに使います。

## 2. Z 行列：結合の長さと角度で書く

Z 行列（Z-matrix）は、原子の位置を、すでに置いた原子からの距離、角度、二面角で書く形式です。
このような座標を内部座標と呼びます。
同じ水分子を Z 行列で書くと、次のようになります。

```text
O
H  1  0.96
H  1  0.96  2  104.5
```

1 行ずつ読むと、次の意味です。

- 1 行目：O を置きます。
- 2 行目：H を、1 番目の原子（O）から 0.96 Å の位置に置きます。
- 3 行目：H を、1 番目の原子から 0.96 Å、2 番目の原子との角度（H–O–H）が 104.5° の位置に置きます。

4 番目以降の原子は、「距離、角度、二面角」の三つの値で位置が決まります。
二面角は、4 個の原子 A–B–C–D について、A–B–C の面と B–C–D の面のなす角です。
たとえば、4 行目に `C  1  1.50  2  110.0  3  120.0` と書くと、C を原子 1 から 1.50 Å、角 C–1–2 を 110.0°、二面角 C–1–2–3 を 120.0° の位置に置きます。

Z 行列が役に立つのは、化学の言葉で構造を指定したいときです。
「この結合の長さだけを少しずつ変える」「この二面角を固定する」といった操作が、1 個の数字を変えるだけで書けます。
一方、環をもつ分子や大きな分子では、書くのが手間です。
3 個の原子が一直線に並ぶと角度が 180° になり、その先の二面角が定まらないという問題もあります。
このときは、どの原子にも属さない仮の点（ダミー原子）を置いて避けます。
書き方の細部はプログラムごとに違うので、使うプログラムのマニュアルで確かめます。

**ここまでで分かったこと**：Z 行列は距離、角度、二面角で構造を書く形式で、特定の結合や角度を動かしたいときに便利です。

## 3. SMILES から 3 次元構造を作る

大きな分子を、座標を一つずつ打ち込んで作るのは大変です。
そこで、分子のつながり方だけを文字列で書き、3 次元の座標は道具に作らせる方法がよく使われます。
つながり方を書く代表的な形式が SMILES（Simplified Molecular Input Line Entry System）です（Weininger, 1988）。

### 3.1 SMILES の読み方

SMILES の基本の決まりは次のとおりです。

- 原子は元素記号で書き、並べた原子は単結合でつながります。`CCO` はエタノールです。
- 水素は、ふつうの価数から自動で補われるので、書きません。
- 二重結合は `=`、三重結合は `#` で書きます。`C=C` はエチレンです。
- 枝分かれは括弧で書きます。`CC(C)C` はイソブタンです。
- 環は、閉じる位置に同じ数字をつけます。`C1CCCCC1` はシクロヘキサンです。
- 芳香環の原子は小文字で書きます。`c1ccccc1` はベンゼンです。
- 電荷や、ふつうでない価数の原子は角括弧で書きます。`[NH4+]` はアンモニウムイオンです。
- 立体化学は `@` や `/`、`\` で書きます。書かないと、どちらの立体異性体ができるかは道具任せになります。

### 3.2 座標を作る道具

SMILES から座標を作る道具は、おおよそ次の手順で動きます。

1. つながり方から、原子間の距離や角度のおおよその範囲を決め、それを満たす座標を作る。
2. 力場（原子間の力を簡単な式で近似したもの）で構造を整える。
3. 必要なら、いくつかの配座を作って、エネルギーの低いものを選ぶ。

ここでは、よく使われる二つの道具、RDKit と Open Babel を紹介します。

**RDKit** は、Python から使う化学情報学のライブラリです。
座標を作る関数 `EmbedMolecule` は、距離幾何（distance geometry）という方法で座標を作ります。
既定では、結晶構造から得たねじれ角の傾向と化学の基本的な知識を距離幾何に加えた ETKDG 法が使われます（Riniker, Landrum, 2015）。
公式の文書は、座標を作る前に水素を明示的に加えるよう勧めています。
次の例は、エタノールの構造を作り、力場 MMFF94 で整えて、xyz 形式で書き出します。

```python
from rdkit import Chem
from rdkit.Chem import AllChem

mol = Chem.AddHs(Chem.MolFromSmiles("CCO"))   # 水素を明示的に足す
params = AllChem.ETKDGv3()
params.randomSeed = 42                          # 結果を再現できるように乱数を固定
AllChem.EmbedMolecule(mol, params)              # 距離幾何で 3 次元座標を作る
AllChem.MMFFOptimizeMolecule(mol)               # 力場（MMFF94）で整える
Chem.MolToXYZFile(mol, "ethanol_rdkit.xyz")
print(Chem.MolToXYZBlock(mol))
```

RDKit 2026.09.2 で動かすと、次の出力が得られました。

```text
9

C     -0.886284    0.164102   -0.072797
C      0.472700   -0.504171   -0.048378
O      1.385279    0.279434    0.706651
H     -0.821053    1.157324   -0.529101
H     -1.605682   -0.435781   -0.637136
H     -1.264380    0.305590    0.945012
H      0.868553   -0.625847   -1.061187
H      0.405268   -1.491959    0.416669
H      1.445597    1.151307    0.280268
```

座標の作り方には乱数が使われるので、乱数の種（`randomSeed`）を固定しないと、実行のたびに少し違う構造ができます。

**Open Babel** は、多くの化学ファイル形式を相互に変換するプログラムです（O'Boyle ら, 2011）。
コマンド `obabel` に `--gen3d` をつけると、3 次元の座標を作ります。

```bash
obabel -:"CCO" --gen3d -oxyz -O ethanol.xyz
```

`-:` の後ろに SMILES を書き、`-oxyz` で出力の形式を、`-O` で出力のファイル名を指定します。
公式の文書によると、`--gen3d` は、規則と部品の型から構造を組み立て、MMFF94 力場で整え、簡単な配座探索をします。
速さと丁寧さは `--fast` や `--best` などの選択肢で変えられます。

### 3.3 自動で作った構造の限界

ここで作った構造は、力場で整えただけのものです。
量子化学計算の出発点としては十分ですが、そのまま結果として使うことはできません。
また、作られるのは多くの配座のうちの一つです。
柔らかい分子では、配座探索をして、エネルギーの低い配座を選んでから最適化します（第 1 回）。

金属錯体は、SMILES と一般的な力場では扱いにくい対象です。
金属と配位子の結合を SMILES でどう書くかに決まった方法がなく、力場にも金属のパラメータが少ないからです。
錯体の構造は、結晶構造から取り出すか、可視化ソフトで組み立てるほうが確実です。

**ここまでで分かったこと**：SMILES でつながり方を書けば、RDKit や Open Babel が 3 次元の座標を作ります。作った構造は計算の出発点で、配座や立体化学は自分で確かめます。

## 4. ASE で構造ファイルを読み書きする

ASE（Atomic Simulation Environment）は、原子の集まりを Python で扱うライブラリです（Larsen ら, 2017）。
xyz 形式をはじめ、多くの形式のファイルを読み書きできます。
次の例は、1 節の水分子の xyz ファイル `water.xyz` を読み、結合の長さと角度を調べ、重心を原点に移して書き出します。

```python
from ase.io import read, write

atoms = read("water.xyz")          # xyz ファイルを読む
print(atoms.get_chemical_formula())
print(atoms.get_chemical_symbols())

d = atoms.get_distance(0, 1)       # O–H 結合の長さ（Å）
a = atoms.get_angle(1, 0, 2)       # H–O–H の角度（度）
print(f"O-H = {d:.4f} Angstrom, H-O-H = {a:.2f} degree")

atoms.translate(-atoms.get_center_of_mass())   # 重心を原点へ移す
write("water_centered.xyz", atoms, comment="water, centered")
```

ASE 3.29.0 で動かした出力です。

```text
H2O
['O', 'H', 'H']
O-H = 0.9578 Angstrom, H-O-H = 104.48 degree
```

書き出したファイル `water_centered.xyz` の中身は次のとおりです。

```text
3
water, centered
O        0.00000000       0.00000000       0.06563331
H        0.00000000       0.75720000      -0.52086669
H        0.00000000      -0.75720000      -0.52086669
```

原子の番号は 0 から数えます。
`get_distance(0, 1)` は 0 番目（O）と 1 番目（H）の距離、`get_angle(1, 0, 2)` は 0 番目の原子を頂点とする角度です。
水素は軽いので、重心は O の近くにあります。
そのため、重心を原点に移すと、分子全体が $-z$ の向きに約 0.05 Å ずれるだけで、O の $z$ 座標は 0 に近い値になりました。

このように、構造を数字として扱えると、多くの構造の結合の長さを一度に調べたり、入力ファイルをまとめて作ったりできます。
ASE で計算をつなぐ方法は、第 14 回（準備中）で扱います。

**ここまでで分かったこと**：ASE の `read` と `write` で構造ファイルを読み書きでき、距離や角度も Python で調べられます。

## 5. 可視化ソフトの役割

構造を作ったら、必ず目で見て確かめます。
計算の結果も、振動の形や分子軌道を絵で見ると理解しやすくなります。
可視化ソフトには、主に次の三つの役割があります。

1. **構造を組み立てる、直す**：原子を置き、結合を引き、角度を調整します。
2. **入力ファイルを作る**：組み立てた構造から、計算プログラムの入力ファイルを書き出します。
3. **結果を見る**：最適化の途中の構造、振動のアニメーション、分子軌道や電子密度の等値面を表示します。

代表的なソフトと、得意なことを表にまとめます。

| ソフト | 種類 | 主な役割 |
|---|---|---|
| GaussView | Gaussian 用の商用ソフト | 構造の作成、Gaussian の入力の作成と実行、振動のアニメーションやスペクトルの表示 |
| Avogadro | 無料、オープンソース | 構造の作成と力場による整形、いくつかの量子化学プログラムの入力の作成、軌道や振動の表示 |
| VESTA | 非商用は無料 | 結晶構造と、電子密度などの 3 次元格子データ（Gaussian cube 形式など）の表示 |
| Jmol | 無料、オープンソース | 多くの形式の構造と計算出力の表示、振動や軌道の表示。Web ページに埋め込める版（JSmol）もある |

Avogadro は、Gaussian、GAMESS、NWChem などの入力を作る拡張機能を備えています（Hanwell ら, 2012）。
VESTA は、もともと結晶構造と 3 次元格子データの表示のために作られたソフトです（Momma, Izumi, 2011）。
分子の計算でも、電子密度やスピン密度を cube 形式で書き出せば、等値面をきれいに描けます。

どのソフトを使う場合も、ソフトが推測して描く結合は、原子間の距離から決めたものです。
結合が描かれていないことは、結合がないことを意味しません。
逆に、遷移状態では、切れかけの結合が描かれたり描かれなかったりします。

**ここまでで分かったこと**：可視化ソフトは、構造の作成、入力の作成、結果の表示に使います。描かれる結合は距離からの推測にすぎません。

## 6. 計算の前に構造を確かめる

計算を始める前に、次の点を確かめると、無駄な計算を減らせます。

- **原子の数と種類**：水素が抜けていないか。結晶構造から取り出した構造では、水素がないことがよくあります。
- **結合の長さ**：C–H はおよそ 1.1 Å、C–C の単結合はおよそ 1.5 Å です。極端に短い距離（たとえば 0.5 Å）があれば、原子が重なっています。
- **立体化学**：キラル中心の向きや、二重結合のシス・トランスが意図どおりか。
- **電荷とスピン**：分子全体の電荷と不対電子の数を決めておく（第 3 回）。

距離は、4 節の ASE の例のように、スクリプトで調べることもできます。

## まとめ

- xyz 形式は「原子数、注釈、元素記号と座標（Å）」の単純な形式で、プログラムの間で構造を受け渡すのに使います。
- Z 行列は距離、角度、二面角で構造を書き、特定の内部座標を動かしたいときに便利です。
- SMILES からは、RDKit や Open Babel で 3 次元構造を作れます。作った構造は出発点で、配座と立体化学を自分で確かめます。
- ASE を使うと、構造ファイルの読み書きや、距離と角度の計算を Python で行えます。
- 可視化ソフトは構造の作成、入力の作成、結果の表示に使い、描かれる結合は距離からの推測です。
