# 第 1 回　計算の流れ：構造を作る、計算する、結果を読む

!!! abstract "この回の道筋"
    量子化学計算は、どのプログラムを使っても、ほぼ同じ手順で進みます。
    この回では、構造を用意してから、エネルギーを比べて記録を残すまでの流れを、一つずつ見ていきます。
    個々のプログラムの書き方は、第 4 回以降で扱います。

    | 節 | 内容 |
    |---|---|
    | 1 | 計算の流れの全体像 |
    | 2 | 構造を用意する |
    | 3 | 計算方法と基底関数を選ぶ |
    | 4 | 構造最適化：エネルギーが動かない点を探す |
    | 5 | 振動解析：極小か遷移状態かを確かめる |
    | 6 | エネルギーを比べる |
    | 7 | 計算の記録を残す |

!!! tip "物理的なイメージ"
    量子化学計算の一連の手順が求めているのは、ポテンシャルエネルギー曲面（量子化学の理論 第 2 回）の上の「意味のある点」と、その点どうしのエネルギーの差です。構造最適化は、地形の谷底（安定な構造）や峠（遷移状態）を探す作業です。振動解析は、その点が本当に谷底か峠かを確かめ、原子の揺れのエネルギーを足す作業です。一点計算は、見つけた点で、より正確なエネルギーを測る作業です。化学で意味をもつのは、全エネルギーそのものではなく、点どうしの差です。

## 1. 計算の流れの全体像

量子化学計算で反応や分子の性質を調べるときは、多くの場合、次の順に進みます。

1. 分子の構造（原子の種類と座標）を用意する。
2. 計算方法と基底関数を選ぶ。
3. 構造最適化で、エネルギーの谷の底（安定な構造）や峠（遷移状態）にあたる構造を探す。
4. 振動解析で、得られた構造が安定な構造（極小）か、遷移状態かを確かめる。
5. 必要なら、より精度の高い方法でエネルギーを計算し直す。
6. 分子どうしのエネルギーを比べて、反応のエネルギーや活性化エネルギーを求める。
7. 入力と出力を、あとから同じ計算ができる形で残す。

この流れは、Gaussian、ORCA、PySCF などのどのプログラムでも変わりません。
違うのは、入力ファイルの書き方と出力の形だけです。
そこで、まず流れそのものを理解しておくと、新しいプログラムを使うときに迷いません。

**ここまでで分かったこと**：計算は「構造 → 方法の選択 → 最適化 → 振動解析 → エネルギーの比較 → 記録」の順に進みます。

## 2. 構造を用意する

計算の出発点は、原子の種類と 3 次元の座標です。
座標は、分子を描くソフトで作るか、結晶構造のデータベースから取り出すか、SMILES（分子を文字列で表す書き方）から自動で作ります。
具体的な作り方は第 2 回で扱います。

ここで大切なのは、出発の構造がおおよそ正しいことです。
構造最適化は、出発点の近くにあるエネルギーの谷を探す方法だからです。
たとえば、出発の構造でメチル基の向きがずれていると、別の谷（別の配座）に落ちることがあります。
配座とは、結合のまわりの回転だけで移り合える構造のことです。
柔らかい分子では、最もエネルギーの低い配座を探す配座探索（conformer search）を先に行うことが勧められています（Bursch ら, 2022）。

**ここまでで分かったこと**：最適化は出発点に近い谷を見つけるだけなので、出発の構造と配座を丁寧に用意します。

## 3. 計算方法と基底関数を選ぶ

次に、どの近似で電子の状態を計算するかを決めます。
決めることは、二つあります。

- **計算方法**：Hartree–Fock（HF）法、密度汎関数理論（DFT）、MP2 法、結合クラスター法など。DFT の場合は、汎関数（B3LYP、PBE0 など）も選びます。
- **基底関数**：分子軌道を表すために使う関数の組です。STO-3G、6-31G(d)、def2-SVP、def2-TZVP などの名前がついています。大きな基底関数ほど精度は上がりますが、計算は重くなります。

方法と基底関数の組を「計算レベル」と呼び、「B3LYP/def2-SVP」のように「方法/基底関数」の形で書きます。
構造最適化と最後のエネルギー計算で、別の計算レベルを使うこともあります。
そのときは「高いレベル//低いレベル」と書きます。
たとえば「PBE0/def2-TZVP//B3LYP/def2-SVP」は、B3LYP/def2-SVP で最適化した構造で、PBE0/def2-TZVP のエネルギーを計算したという意味です。
このように分ける理由は、構造がエネルギーほど計算レベルに敏感ではないからです（Bursch ら, 2022）。
重い計算は最後の 1 回だけにして、計算時間を節約できます。

DFT では、分子間や分子内の弱い引力（分散力）を補う分散補正（D3、D4 など）を加えることが勧められています（Bursch ら, 2022）。
同じ総説では、B3LYP/6-31G* を分散補正なしで使う組み合わせは、すでに古いと述べられています。
方法と基底関数の指定のしかたは第 3 回で、それぞれの理論は連載「量子化学の理論」で扱います。

**ここまでで分かったこと**：計算レベルは「方法/基底関数」で表します。構造は軽いレベル、エネルギーは重いレベルで計算する分け方がよく使われます。

## 4. 構造最適化：エネルギーが動かない点を探す

原子核の位置を決めると、電子のエネルギーが一つ決まります（Born–Oppenheimer 近似）。
原子の座標を変数とするこのエネルギーの関数を、ポテンシャルエネルギー曲面（PES）と呼びます。
安定な分子は PES の谷の底に、遷移状態は谷と谷をつなぐ峠に対応します。

谷の底でも峠でも、エネルギーを座標で微分した勾配はゼロになります。
勾配がゼロの点を停留点（stationary point）と呼びます。
構造最適化は、勾配を計算しては原子を少し動かすことを繰り返し、停留点を探す手続きです（Schlegel, 1982）。
勾配の符号を変えたものは原子に働く力なので、「力がゼロになるまで原子を動かす」と言い換えることもできます。

最適化がいつ終わったかは、プログラムが決めた収束判定で決まります。
多くのプログラムは、力の大きさと、1 回に動かした距離の大きさの両方を調べます。
すべてが閾値より小さくなったとき、停留点に着いたとみなします。
Gaussian での具体的な判定の読み方は第 4 回で扱います。

ただし、勾配がゼロというだけでは、谷の底なのか峠なのかは分かりません。
これを確かめるのが、次の振動解析です。

**ここまでで分かったこと**：構造最適化は勾配（力）がゼロの停留点を探します。停留点が谷の底か峠かは、まだ分かりません。

## 5. 振動解析：極小か遷移状態かを確かめる

停留点のまわりで、エネルギーを座標の 2 次まで展開します。
2 次の係数を並べた行列が、エネルギーの 2 階微分の行列（ヘシアン、Hessian）です。
ヘシアンの各成分を、かかわる 2 個の原子の質量の平方根で割って重みをつけ（質量加重）、対角化すると、固有値から振動数が、固有ベクトルから振動の形（基準振動）が得られます。
固有値を $\lambda$ とすると、振動の角振動数は $\omega = \sqrt{\lambda}$ です。

この手続きは、停留点でだけ意味を持ちます（Gaussian の Freq の説明にも、停留点以外では意味がないと書かれています）。
勾配がゼロでないと、エネルギーの展開に 1 次の項が残るからです。
そのため、振動解析は、必ず最適化と**同じ計算レベル**で、最適化で得た構造に対して行います。

固有値が正の方向は、どちらに動いてもエネルギーが上がる方向です。
固有値が負の方向は、動くとエネルギーが下がる方向です。
負の固有値の平方根は虚数になるので、この振動を虚振動（imaginary frequency）と呼びます。
多くのプログラムは、虚振動を負の数として出力します。
停留点の種類は、虚振動の数で次のように判定します。

| 虚振動の数 | 停留点の種類 |
|---|---|
| 0 | 極小（安定な分子、中間体） |
| 1 | 1 次の鞍点（遷移状態） |
| 2 以上 | 高次の鞍点（求めたい構造ではない） |

例として、手元で水分子の HF/STO-3G の振動解析をしました（第 4 回、第 5 回で使う計算と同じものです）。
最適化した折れ曲がり構造では、振動数は 3 個（$3N-6 = 3$）で、すべて正でした。
一方、わざと直線にした構造では、変角振動にあたる 2 個の縮重した振動が虚振動になりました。
直線構造は、曲がるとエネルギーが下がる高次の鞍点だということです。

遷移状態を求めたときは、虚振動が 1 個であることに加えて、その振動の形が目的の反応の向き（結合が切れる、できる向き）になっているかを、可視化ソフトで確かめます。
さらに、遷移状態から谷へ下る経路（固有反応座標、IRC）をたどると、どの反応物とどの生成物をつなぐ峠なのかを確かめられます（Fukui, 1981）。

振動解析からは、零点振動エネルギーや、温度による補正も得られます。
これらを使って自由エネルギーを求める方法は、第 5 回で扱います。

**ここまでで分かったこと**：振動解析で虚振動を数えると、極小（0 個）か遷移状態（1 個）かが分かります。振動解析は最適化と同じ計算レベルで行います。

## 6. エネルギーを比べる

一つの分子の全エネルギーの値そのものには、ほとんど意味がありません。
意味を持つのは、同じ原子の組をもつ二つの状態の差です。
たとえば反応 A + B → C の反応エネルギーは、次の式で求めます。

$$
\Delta E = E(\mathrm{C}) - \left[ E(\mathrm{A}) + E(\mathrm{B}) \right]
$$

活性化エネルギーは、遷移状態のエネルギーから反応物のエネルギーを引いて求めます。

差をとるときは、次の三つをそろえます。

1. **計算レベルをそろえる。** 方法、基底関数、分散補正、溶媒モデルが一つでも違うと、差に意味がなくなります。
2. **計算の設定をそろえる。** DFT の積分グリッドや、有効内殻ポテンシャルの使い方なども、全エネルギーを少し変えます。同じプログラムの同じ設定で計算した値どうしを比べます。
3. **エネルギーの種類をそろえる。** 電子エネルギー、零点振動補正を加えたエネルギー、エンタルピー、自由エネルギーのどれを比べているのかを明記します。

プログラムの出力は、多くの場合、ハートリー（$E_\mathrm{h}$、原子単位のエネルギー）で書かれています。
化学でよく使う単位には、1 $E_\mathrm{h}$ = 627.5 kcal/mol = 27.211 eV で換算します。
たとえば、差が $-0.0100\ E_\mathrm{h}$ なら、$-6.28$ kcal/mol です。
全エネルギーは桁の多い数なので、出力の値を丸めずに使い、差をとってから丸めます。

**ここまでで分かったこと**：エネルギーは差だけに意味があります。計算レベル、設定、エネルギーの種類をそろえてから差をとります。

## 7. 計算の記録を残す

計算は、あとで自分や他人が同じ結果を出せるように記録します。
数か月後に論文の補足資料を作るとき、どの設定で計算したかが分からないと、計算をやり直すことになります。
残すものは、次のとおりです。

- **入力ファイルと出力ファイル**：出力には、プログラムの版、使った方法、収束の様子がすべて書かれています。出力を消さずに残します。
- **最適化した構造**：xyz 形式などで、別のファイルとしても保存します。論文の補足資料にもそのまま使えます。
- **プログラムの名前と版**：同じ方法でも、版によって既定の設定が変わることがあります。
- **計算レベルと主な設定**：方法、基底関数、分散補正、溶媒、温度、そして既定値から変えたキーワード。
- **確かめた結果**：虚振動の数、収束したかどうか、スピンの期待値（開殻の場合。第 3 回）など。

フォルダは、分子ごと、または反応の段階ごとに分けると、あとで探しやすくなります。
エネルギーの表は、手で写さず、出力から読み取るスクリプトで作ると、写し間違いを防げます。
データを、見つけやすく、他人も使いやすい形で残すための指針として、FAIR 原則（Findable, Accessible, Interoperable, Reusable）が提案されています（Wilkinson ら, 2016）。

**ここまでで分かったこと**：入力、出力、構造、プログラムの版、設定、確かめた結果を残すと、計算をあとから再現できます。

## まとめ

- 計算は「構造 → 計算レベルの選択 → 構造最適化 → 振動解析 → エネルギーの比較 → 記録」の順に進みます。
- 構造最適化は勾配がゼロの停留点を探し、振動解析の虚振動の数で極小（0 個）か遷移状態（1 個）かを判定します。
- 振動解析は、最適化と同じ計算レベルで、最適化した構造に対して行います。
- エネルギーは差だけに意味があり、計算レベルと設定とエネルギーの種類をそろえて比べます。
- 入力と出力、プログラムの版、設定を残して、計算を再現できるようにします。
