# 講義ノート

量子化学に携わるための知識を、いくつかの連載に分けて書いていきます。
各回には難しさの目安を付けます。

| 目安 | 意味 |
|---|---|
| 入門 | 学部の量子化学（水素原子、分子軌道の考え方）を知っていれば読める |
| 基礎 | Szabo–Ostlund の Hartree–Fock 法まで分かっていれば読める |
| 発展 | 研究で使われている方法の中身 |
| 最先端 | ここ数年の研究の話題 |

## 読み方

- 各回のはじめに「この回の道筋」と「前に読んでおく回」を書きます。
- 深い導出は各回の付録にまとめ、本文では結果を使います。
- 手で確かめられる小さな計算例（Python）を、できるだけ付けます。
