# 化学反応の理論

量子化学で計算したポテンシャルエネルギー曲面から、反応の起こりやすさ、速さ、選択性を読み解く理論を学びます。
遷移状態と反応経路、反応速度の理論、軌道による反応性の理解、電子移動と触媒反応を順に扱い、最後に化学反応理論の最前線の話題まで進みます。
