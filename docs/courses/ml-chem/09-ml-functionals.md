## 1. 交換相関汎関数を学習するとは

### 1.1 Kohn–Sham 法で近似が入るところ

Kohn–Sham 法では、電子のエネルギーを次のように分けます（原子単位）。

$$
E[\rho] = T_\mathrm s[\rho] + \int v_\text{ext}(\mathbf r)\rho(\mathbf r)\,d\mathbf r + J[\rho] + E_\text{xc}[\rho].
$$

$\rho$ は電子密度、$T_\mathrm s$ は相互作用しない電子の運動エネルギー、$v_\text{ext}$ は核が作るポテンシャル、$J$ は密度どうしの古典的なクーロン反発です。
最後の $E_\text{xc}$ が交換相関汎関数で、ほかの項に入らない量子力学的な効果をすべて引き受けます。
$E_\text{xc}$ の正確な形は分かっていないので、近似が必要です。
DFT の計算の誤差の多くは、この近似から来ます。

軌道は、次の Kohn–Sham 方程式を解いて求めます。

$$
\left[-\tfrac12\nabla^2 + v_\text{ext}(\mathbf r) + v_\mathrm J(\mathbf r) + v_\text{xc}(\mathbf r)\right]\phi_i(\mathbf r) = \varepsilon_i\phi_i(\mathbf r),
\qquad
v_\text{xc}(\mathbf r) = \frac{\delta E_\text{xc}}{\delta\rho(\mathbf r)} .
$$

$v_\mathrm J$ はクーロン反発のポテンシャルです。
$v_\text{xc}$ は、$E_\text{xc}$ を密度で微分（汎関数微分）したものです。
ポテンシャルが密度によるので、方程式は、密度を仮定して解き、得た密度でポテンシャルを作り直す、というくり返しで解きます。
これが自己無撞着場（self-consistent field、SCF）の計算です。
この式から分かるように、汎関数を使うには、エネルギーの値だけでなく、その微分も必要です。

### 1.2 従来の汎関数の形

多くの汎関数は、空間の各点 $\mathbf r$ で決まる量から、その点の「エネルギー密度」を作り、それを積分する形をしています。
各点で使う量は、汎関数の種類で決まります。

- LDA：密度 $\rho$
- GGA：さらに密度の勾配 $|\nabla\rho|$
- メタ GGA：さらに運動エネルギー密度 $\tau = \frac12\sum_i |\nabla\phi_i|^2$
- 混成汎関数：さらに HF の交換エネルギー（の一部）

この順番は「Jacob のはしご」と呼ばれ、上の段ほど精度が上がることが多い一方、計算は重くなります。
HF の交換エネルギーは、2 つの点 $\mathbf r$ と $\mathbf r'$ の両方にわたる積分なので、その点の近くだけでは決まりません（非局所的）。

### 1.3 機械学習の汎関数

機械学習の汎関数は、各点の量から、その点のエネルギー密度への寄与を決める部分を、ニューラルネットワークで表します。
学習には、精度の高い波動関数法で求めた反応エネルギーや原子化エネルギーなどを使います。

これは、第 3〜7 回の機械学習ポテンシャルとは、使い方が大きく違います。
機械学習ポテンシャルは、構造からエネルギーを直接返し、量子化学計算を置き換えます。
機械学習の汎関数は、Kohn–Sham 法の中の 1 つの部品を置き換えるだけで、計算は普通の DFT と同じように SCF で行います。
そのため、軌道、電荷、スピン、長距離の静電相互作用は、Kohn–Sham 法の枠組みが正しく扱います。
第 7 回で見た「学習データにない電荷やスピンの値に一般化しにくい」という問題は、この点では起きません。
その代わり、計算は DFT と同じだけ重く、SCF が収束しないという新しい問題が起きます（5 節）。

**ここまでで分かったこと**：機械学習の汎関数は、Kohn–Sham 法の交換相関汎関数をニューラルネットワークで表します。SCF の中で使うので、エネルギーだけでなく、その微分も必要です。

## 2. 分数電荷と分数スピン

### 2.1 厳密な汎関数が満たす条件

DM21 を理解するには、厳密な汎関数が満たす 2 つの条件を知っておく必要があります。
どちらも、電子の数やスピンが整数でない「仮想的な系」についての条件です。

1 つ目は**分数電荷**の条件です。
電子の数 $N$ が整数 $N_0$ と $N_0+1$ の間にあるとき、厳密なエネルギーは、両端のエネルギーを直線で結んだ値になります [Perdew 1982]。

$$
E(N_0 + \delta) = (1-\delta)\,E(N_0) + \delta\, E(N_0+1), \qquad 0 \le \delta \le 1 .
$$

2 つ目は**分数スピン**の条件です。
縮退した基底状態を混ぜた、スピンが分数の状態のエネルギーは、もとの整数スピンの状態のエネルギーと等しく、一定でなければなりません [Cohen 2008b]。

普通の近似汎関数は、どちらの条件も破ります。
分数電荷では、多くの汎関数で $E(N)$ が直線より下に膨らみ（下に凸）、電子が実際より広がった状態を好みます。
Mori-Sánchez、Cohen、Yang は、この直線からのずれを非局在化誤差（delocalization error）と呼び、バンドギャップの問題などと結び付けました [Mori-Sánchez 2008]。
分数スピンの条件の破れは、結合の解離などで現れる静的相関の誤差と結び付けられています [Cohen 2008b]。
これらの誤差の見方は、総説 [Cohen 2008a] にまとまっています。

### 2.2 計算例：H₂⁺ の解離

分数電荷の条件の破れは、電子が 1 個しかない H₂⁺ で、はっきり見えます。
電子が 1 個なら、HF 法は（この基底関数の範囲で）厳密です。
自分自身との反発と、自分自身との交換がちょうど打ち消し合うからです。

核間距離 $R$ を大きくすると、H₂⁺ は H 原子と H⁺ に分かれます。
そのため、$E(\mathrm{H_2^+}) - E(\mathrm H)$ は、$R$ が大きいところで 0 に近づくはずです。
ここでは、2 つの核に均等に広がった解を求めるため、分子の対称性を保って計算します。

```python
from pyscf import gto, scf, dft

basis = "cc-pvtz"
def energy(method, atom, charge, spin):
    mol = gto.M(atom=atom, basis=basis, charge=charge, spin=spin,
                symmetry=True, verbose=0)  # 対称性を保った（2 つの核に均等に広がった）解を求める
    if method == "HF":
        return scf.UHF(mol).run().e_tot
    return dft.UKS(mol, xc=method).run().e_tot

methods = ["HF", "pbe", "b3lyp", "wb97x"]
# 解離の極限 H + H+ のエネルギー（H 原子 1 個のエネルギー）
e_inf = {m: energy(m, "H 0 0 0", 0, 1) for m in methods}
print(" R/Å   " + "".join(f"{m:>9s}" for m in methods) + "   （E(H2+) - E(H)、kcal/mol）")
for r in [1.06, 2.0, 3.0, 5.0, 10.0]:
    row = [(energy(m, f"H 0 0 0; H 0 0 {r}", 1, 1) - e_inf[m]) * 627.5 for m in methods]
    print(f"{r:5.2f} " + "".join(f"{v:9.1f}" for v in row))
```

```text
 R/Å          HF      pbe    b3lyp    wb97x   （E(H2+) - E(H)、kcal/mol）
 1.06     -64.3    -68.6    -67.6    -68.2
 2.00     -31.9    -52.0    -48.0    -44.5
 3.00      -8.4    -44.6    -37.7    -27.2
 5.00      -0.4    -50.4    -41.1    -21.6
10.00      -0.0    -58.6    -47.5    -21.3
```

HF（厳密）の値は、$R$ が大きくなると 0 に近づきます。
一方、3 つの汎関数の値は、10 Å でも −20〜−60 kcal/mol にとどまります。
PBE と B3LYP では、5 Å から 10 Å にかけて、かえって低くなっています。
離れた 2 つの陽子が電子を引き合う力はほとんどないので、これは物理的にありえない結果です。

これが分数電荷の条件の破れです。
$R$ が十分大きいとき、2 つの核に均等に広がった解は、「電子 1/2 個をもつ H 原子」が 2 つある状態とみなせます。
分数電荷の条件が成り立てば、そのエネルギーは $2 \times \frac12\left[E(\mathrm H^+) + E(\mathrm H)\right] = E(\mathrm H)$ になります（$E(\mathrm H^+) = 0$）。
近似汎関数の $E(N)$ は直線より下に膨らむので、電子 1/2 個の H 原子のエネルギーが低すぎ、全体も低すぎる値になります。
範囲分離混成汎関数の ωB97X では誤差が小さくなりますが、0 にはなりません。

**ここまでで分かったこと**：厳密な汎関数は、分数電荷では直線、分数スピンでは一定という条件を満たします。近似汎関数はこれを破り、H₂⁺ の解離のような単純な系でも数十 kcal/mol の誤差を生みます。

## 3. DM21：分数電荷と分数スピンをデータに入れる

### 3.1 考え方

DM21（DeepMind 21）は、2021 年に Kirkpatrick らが Science に発表した機械学習の汎関数です [Kirkpatrick 2021]。
要旨によれば、この研究の考え方は次のとおりです。
従来の近似汎関数の系統的な誤差は、厳密な汎関数が満たす数学的な性質を破ることから来ています。
そこで、ニューラルネットワークを、分子のデータだけでなく、分数電荷と分数スピンをもつ仮想的な系のデータでも学習させました [Kirkpatrick 2021]。
つまり、2 節の条件を、式で課すのではなく、学習データとして与えたのです。

DM21 が各点で使う量について、DM21 を解析した論文は次のように説明しています [Zhao 2024]。
密度とその勾配、運動エネルギー密度に加えて、各点での HF の交換エネルギー密度と、その長距離部分（距離の逆数のクーロン相互作用を誤差関数で長距離と短距離に分けたときの長距離部分、範囲分離のパラメーター $\omega = 0.4$）を使います。
後の 2 つは 1.2 節で見た非局所的な量なので、DM21 は混成汎関数と同じ段の材料を使っていることになります。

分数スピンの学習の例として、解析の論文は、スピン分極のない H 原子で学習することで、スピン対称性を破らずに H₂ の正しい解離の極限が得られることを挙げています [Zhao 2024]。

### 3.2 報告された結果

要旨によれば、DM21 は、人工的な電荷の非局在化と強い相関の典型例を正しく記述し、主族元素の原子と分子の詳しいベンチマークで従来の汎関数より良い結果を示しました [Kirkpatrick 2021]。
水素の鎖、電荷をもつ DNA 塩基対、ジラジカルの遷移状態のような系も正確に扱えたと報告しています [Kirkpatrick 2021]。

### 3.3 その後の議論

DM21 の発表後、その主張を検証する研究がいくつも出ました。

**分数電荷・分数スピンの一般化について**。
Gerasimov らは、Science へのコメントで、DM21 が学習データの外で分数電荷と分数スピンの振る舞いを一般化できることは、発表された結果からは言えないと主張しました [Gerasimov 2022]。
著者らの返答によれば、その根拠の 1 つは、学習データと、結合の解離のベンチマークの間に約 50% の重なりがあるという指摘でした [Kirkpatrick 2022]。
著者らはこの分析に同意せず、指摘は誤りか、論文の主な結論に関係しないと答えています [Kirkpatrick 2022]。
この点は、学習データとベンチマークの重なりをどう数えるかに関わり、読者が両方を読んで判断する必要があります。

**水について**。
Palos らは、DM21 で水のクラスターを調べ、エネルギーの精度がクラスターの大きさによって大きく変わることを報告しました [Palos 2022]。
DM21 のデータから作った多体のポテンシャルで液体の水を計算すると、水素結合を強く見積もりすぎ、室温で氷に近い局所構造になりました [Palos 2022]。

**遷移金属について**。
DM21 の学習データには、Kr より重い元素が含まれていません [Zhao 2024]。
Zhao、Gould、Vuckovic は、遷移金属の化学に DM21 を使ったときの振る舞いを調べました [Zhao 2024]。
結果は次のとおりです。

- SCF が収束した場合の精度は、B3LYP と同程度で、ときにはそれより良い。
- しかし SCF の収束に苦労することが多く、遷移金属を含む 117 の反応のデータで、約 30% の反応は DM21 で SCF が収束しなかった。
- SCF のくり返しを使わず、軌道を直接最適化する方法でも収束しない系があった。

最後の点から、論文は、DM21 は、学習データの外にある入力の組み合わせで、ほとんど不連続なほど急に変わる関数になっているのだろうと考察しています [Zhao 2024]。
同じ論文は、主族元素の原子化エネルギーのデータ（W4-11）の 152 の化学種はすべて最初の設定で収束したことも報告しています [Zhao 2024]。
学習データに近い主族元素の系では問題が起きず、学習データから離れた遷移金属で問題が起きた、ということです。
これは、第 6 回で見た「分布の外では信用できない」ことの、汎関数での現れ方です。

**ここまでで分かったこと**：DM21 は、分数電荷と分数スピンの条件をデータとして学習し、主族元素で良い結果を示しました。一方、条件の一般化には議論があり、学習データの外の遷移金属では SCF が収束しないことが多いと報告されています。

## 4. Skala：非局所的な特徴をデータから学ぶ

### 4.1 考え方

Skala は、Microsoft Research のグループが 2025 年に arXiv に発表した機械学習の汎関数です [Luise 2025]。
（arXiv の論文は改訂されています。以下は、第 6 版で確かめた内容です。）

Skala の考え方は、Jacob のはしごを上らずに精度を上げることです。
入力には、メタ GGA と同じ、各点の安い量だけを使います [Luise 2025]。
そのうえで、積分の格子点の間で情報をやり取りする部分をニューラルネットワークに持たせ、非局所的な効果をデータから学ばせます。
格子点の間のやり取りは、原子を中心とした粗い点を経由させ、計算量が半局所の汎関数（LDA、GGA、メタ GGA）と同じ増え方になるように作られています [Luise 2025]。
つまり、HF の交換を使わずに、混成汎関数並みの精度を、半局所の汎関数の計算量で得ることを目指しています。
分散力は学習せず、D3 の補正を固定して加えています [Luise 2025]。

### 4.2 学習データと学習の仕方

学習データの中心は、著者らが作った MSR-ACC という高精度のデータの集まりです [Luise 2025]。
本文によれば、W1-F12 や W1w という CCSD(T)/CBS 相当の精度の熱化学の手順で計算した、約 39 万 5 千のエネルギー差を含みます。
最も大きな部分は、約 12 万の分子の全原子化エネルギーです [Luise 2025]。
これに、公開されている同程度以上の精度のデータが約 8 万加えられています。

学習は 2 段階です [Luise 2025]。

1. **事前学習**：B3LYP で求めた密度を固定して、その密度で評価したエネルギーが正解に合うように学習する。SCF を回さないので、多くのデータを安く使える。
2. **SCF での微調整**：学習中に、そのときの汎関数で SCF を回して密度を作り、その密度で学習する。

2 段階に分けるのは、学習の初めの汎関数は正確さからほど遠く、SCF が多くの系で収束しないからだと説明されています [Luise 2025]。
2 段階目は、汎関数を固定の密度で評価したときの精度と、自分の SCF の密度で評価したときの精度の差を埋めるためのものです。
論文は、この微調整で、エネルギーと密度（双極子モーメントで評価）が同時に良くなったことから、エネルギーの改善が密度の誤差との打ち消し合いによるものではないと考察しています [Luise 2025]。

### 4.3 報告された結果

要旨によれば、主族元素の化学のベンチマーク GMTKN55 で、Skala の誤差の指標（WTMAD-2）は 2.8 kcal/mol で、最先端の混成汎関数を上回り、計算量は半局所の汎関数並みです [Luise 2025]。
本文では、原子化エネルギーのベンチマーク W4-17 で、単参照的な 183 の分子について平均絶対誤差 0.92 kcal/mol、多参照的な分子を含む 200 の分子全体で 1.23 kcal/mol と報告しています [Luise 2025]。
学習データとテストデータの重なりは、分子のグラフが一致するものを学習データから除くことで避けたと書かれています [Luise 2025]。
非局所的な部分を外した「局所的なモデル」と比べると、非局所的な部分によって、GMTKN55 の縮小版での誤差が平均で約半分になりました [Luise 2025]。

### 4.4 論文が挙げている限界

論文自身が、次の点を書いています [Luise 2025]。

- SCF の収束は、従来の汎関数より少し難しい。収束しないときのために、レベルシフトなどを順に試す手順を用意している。
- 遷移金属については、3d と 4d の遷移金属の原子についての最小限のデータを学習に加えた段階である。
- 多参照的で強い相関をもつ系に広げることが大きな課題で、そのための精度の高いデータを大量に作ることが難しい。

**ここまでで分かったこと**：Skala は、メタ GGA の安い入力から、非局所的な効果をデータで学ぶ汎関数です。大量の高精度データで、主族元素では混成汎関数を上回る精度を、半局所の汎関数の計算量で報告しています。

## 5. 何が難しいか

ここまでの 2 つの例から、機械学習の汎関数に特有の難しさを整理します。

### 5.1 SCF の安定性と汎関数の微分

1.1 節で見たように、SCF では、エネルギーの汎関数微分 $v_\text{xc}$ が必要です。
ニューラルネットワークの微分は自動微分で計算できます。
しかし、エネルギーの値が学習データに合っていても、その微分が滑らかとは限りません。
エネルギーだけを学習すると、微分の振る舞いは直接には制御されないからです。
DM21 の解析では、学習データの外の入力で、汎関数がほとんど不連続に変わることが、SCF の収束の失敗の原因と考えられています（3.3 節）[Zhao 2024]。

### 5.2 SCF を通した学習の重さ

汎関数は、最終的には自分自身の SCF の密度で使われます。
そのため、本来は「自分の SCF の密度で評価したエネルギー」が正解に合うように学習したいのですが、学習のたびに SCF を回すのは重い計算です。
Skala は、固定した B3LYP の密度での事前学習と、SCF での微調整に分け、さらに微調整では SCF のくり返しを通した微分を計算しない方法で、この問題に対処しています [Luise 2025]。
DM21 も、B3LYP の密度での学習を使っていると、解析の論文は説明しています [Zhao 2024]。

### 5.3 外挿

機械学習の汎関数も、学習データの分布の外では信用できません。
ただし、機械学習ポテンシャルとは「分布」の意味が違います。
機械学習ポテンシャルで問題になるのは、構造、元素、電荷、スピンの分布でした（第 6 回）。
機械学習の汎関数で問題になるのは、各点の入力の量（密度、勾配、運動エネルギー密度など）の組み合わせの分布です。
DM21 の解析は、遷移金属の原子のような単純な系でも、学習データの外の入力の組み合わせが現れることを示しました [Zhao 2024]。

### 5.4 分かっていることと、分かっていないこと

- 分かっていること：主族元素の化学では、大量の高精度データで学習した機械学習の汎関数が、ベンチマークで従来の混成汎関数を上回る精度を出せること [Luise 2025]。分数電荷・分数スピンの条件をデータで与えると、それらの条件に関わる典型例の振る舞いが改善すること [Kirkpatrick 2021]。
- 分かっていないこと：学習データにない種類の系（遷移金属、強い相関、固体など）にどこまで外挿できるか。分数電荷・分数スピンの条件が学習データの外でも成り立つか（3.3 節の議論）。SCF の安定性を、学習の段階でどう保証するか。

**ここまでで分かったこと**：機械学習の汎関数の難しさは、SCF に使う微分の滑らかさ、自分の密度で学習することの重さ、入力の組み合わせの外挿にあります。

## まとめ

- 機械学習の汎関数は、Kohn–Sham 法の交換相関汎関数の部分をニューラルネットワークで表します。電荷やスピンは Kohn–Sham 法の枠組みが扱いますが、SCF のためにエネルギーの微分も必要です。
- 厳密な汎関数は、分数電荷では直線、分数スピンでは一定という条件を満たします。近似汎関数はこれを破り、H₂⁺ の解離でも大きな誤差を生みます。
- DM21 は、これらの条件をデータとして学習しました。一方、条件の一般化には議論があり、遷移金属では SCF が収束しないことが多いと報告されています。
- Skala は、メタ GGA の入力から非局所的な効果を学び、主族元素で混成汎関数を上回る精度を、半局所の汎関数の計算量で報告しています。
- 難しさは、SCF の安定性と汎関数の微分、自分の密度で学習することの重さ、入力の組み合わせの外挿にあります。
