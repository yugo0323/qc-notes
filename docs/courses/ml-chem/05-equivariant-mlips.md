## 1. 不変と等変

### 1.1 定義

分子を回転行列 $\mathsf Q$ で回したとき、ある量 $f$ がどう変わるかを考えます。
原子の位置をまとめて $\mathbf R$、回した後の位置を $\mathsf Q\mathbf R$ と書きます。

- **不変**（invariant）：$f(\mathsf Q\mathbf R) = f(\mathbf R)$。回しても変わらない量です。エネルギー、HOMO-LUMO ギャップ、原子間の距離がその例です。
- **等変**（equivariant）：$f(\mathsf Q\mathbf R) = \mathsf D(\mathsf Q)\, f(\mathbf R)$。回すと、決まった規則 $\mathsf D(\mathsf Q)$ で一緒に変わる量です。

ベクトルなら $\mathsf D(\mathsf Q) = \mathsf Q$ で、力や双極子モーメントがその例です（第 1 回 4.3 節）。
分極率のような 2 階のテンソル $\mathsf T$ は、$\mathsf T \to \mathsf Q \mathsf T \mathsf Q^\mathsf T$ と変わります。
不変は、$\mathsf D(\mathsf Q)$ が 1（何もしない）の特別な場合と見ることができます。

### 1.2 出力は不変でも、中身は等変にできる

エネルギーを予測するモデルの出力は、不変でなければなりません。
第 2 回では、そのために入力（記述子）の段階で不変にしました。
第 4 回の SchNet も、距離だけを使うことで、途中の量をすべて不変にしています。

しかし、途中の量まで不変である必要はありません。
途中の量が等変で、最後に不変な量を取り出せば、出力は不変になります。
NequIP と MACE は、この「中身は等変、出力は不変」という設計を取りました。
なぜそうするのかを、次の節で見ます。

**ここまでで分かったこと**：不変は回しても変わらない量、等変は回すと決まった規則で一緒に変わる量です。モデルの途中の量は、等変にしてもかまいません。

## 2. 向きの情報を捨てない理由

### 2.1 計算例：距離だけの和では角度が分からない

中心の原子のまわりに、1.0 Å の距離で 2 個の原子がある環境を 2 つ考えます。
2 本の結合のなす角が 90° の場合と 180° の場合です。
まわりの原子についての和を、2 通りに作ります。

- スカラーの和：$s = \sum_j g(r_j)$。距離だけを使います。
- ベクトルの和：$\mathbf v = \sum_j g(r_j)\, \hat{\mathbf r}_j$。$\hat{\mathbf r}_j$ は中心から原子 $j$ への単位ベクトルで、向きの情報を残します。

$g$ は距離だけで決まる重みで、ここでは $g(r) = e^{-r^2}$ とします。

```python
import numpy as np

def g(r):
    return np.exp(-r**2)            # 距離だけで決まる重み（何でもよい）

def env(angle_deg):
    """中心の原子から 1.0 Å の位置に 2 個の原子。2 本の結合のなす角を指定"""
    t = np.radians(angle_deg)
    return np.array([[1.0, 0.0, 0.0], [np.cos(t), np.sin(t), 0.0]])

for angle in (90, 180):
    r_vec = env(angle)
    r = np.linalg.norm(r_vec, axis=1)
    s = g(r).sum()                                     # 不変な量（スカラー）だけの和
    v = (g(r)[:, None] * r_vec / r[:, None]).sum(0)    # 向きを残した和（ベクトル）
    print(f"{angle:3d}°: スカラーの和 {s:.4f}   ベクトルの和 {np.round(v, 4)}"
          f"   その長さの 2 乗 {v @ v:.4f}")
```

```text
 90°: スカラーの和 0.7358   ベクトルの和 [0.3679 0.3679 0.    ]   その長さの 2 乗 0.2707
180°: スカラーの和 0.7358   ベクトルの和 [0. 0. 0.]   その長さの 2 乗 0.0000
```

スカラーの和は、2 つの環境で同じです。
距離が同じなので、距離だけを足しても区別できません。
ベクトルの和は違います。
そして、その長さの 2 乗 $\mathbf v \cdot \mathbf v$ は回転で変わらない量なので、エネルギーの計算に使えます。

### 2.2 和の積から角度が出てくる

$\mathbf v \cdot \mathbf v$ を書き下すと、次のようになります。

$$
\mathbf v \cdot \mathbf v = \sum_j \sum_k g(r_j)\, g(r_k)\, \hat{\mathbf r}_j \cdot \hat{\mathbf r}_k
= \sum_j \sum_k g(r_j)\, g(r_k) \cos\theta_{jk} .
$$

$\theta_{jk}$ は、中心から見た原子 $j$ と $k$ のなす角です。
つまり、$\mathbf v \cdot \mathbf v$ は、中心の原子とまわりの 2 原子の関係（3 体の情報）を含んでいます。
ここで大事なのは、計算の手順です。
まわりの原子について 1 回和を取って $\mathbf v$ を作り、それと自分自身の内積を取るだけで、原子の組についての二重和が得られました。
組を 1 つずつ数え上げる必要はありません。
この「先に和を取り、あとで掛け合わせる」という考え方は、5 節の MACE の中心になります。

1 回のメッセージパッシングで、中心の原子が受け取る量を考えると、違いがはっきりします。
SchNet のように距離だけで決まるメッセージを足すと、受け取る量は $s$ と同じ種類の量で、角度は分かりません。
ベクトルのような向きを持つ量のまま足し、あとで組み合わせれば、角度が分かります。
これが、モデルの中で等変な量を扱う動機です。

**ここまでで分かったこと**：向きを持つ量のまわりの原子についての和を取り、あとで内積などで組み合わせると、角度の情報が得られます。距離だけの和では得られません。

## 3. 球面調和関数とテンソル積

ベクトルより複雑な「向きの情報」を扱うために、NequIP と MACE は球面調和関数とテンソル積を使います。
どちらも、量子化学の角運動量で出てくるものと同じ数学です。

### 3.1 球面調和関数：向きを s, p, d, … に分ける

単位ベクトル $\hat{\mathbf r}$ の関数として、球面調和関数 $Y_{lm}(\hat{\mathbf r})$ を考えます。
$l = 0, 1, 2, \dots$ ごとに $2l+1$ 個の関数があり、それぞれ s, p, d, … 軌道の角度部分の形をしています。

- $l = 0$：定数が 1 個。向きによりません。
- $l = 1$：3 個。実数の形にすると、$\hat{\mathbf r}$ の $x, y, z$ 成分に比例します。2.1 節のベクトルの和は、$l = 1$ の量でした。
- $l = 2$：5 個。$\hat{\mathbf r}\hat{\mathbf r}^\mathsf T - \frac{1}{3}\mathsf I$（3×3 の対称でトレースが 0 の行列）の独立な成分の組み合わせです。

球面調和関数の大事な性質は、回したときに同じ $l$ の $2l+1$ 個の関数の間でだけ混ざることです。
p 軌道を回すと p 軌道どうしで混ざり、d 軌道にはならないのと同じです。
したがって、$l$ ごとにまとめた量は、それぞれ決まった規則（$(2l+1) \times (2l+1)$ の行列）で回転と一緒に変わる、等変な量です。
NequIP の論文は、この $l$ を「回転の次数」（rotation order）と呼んでいます [Batzner 2022]。

### 3.2 テンソル積：角運動量の合成と同じ

2 つの等変な量を組み合わせて、新しい等変な量を作る操作がテンソル積です。
$l_1$ の量と $l_2$ の量のテンソル積からは、

$$
|l_1 - l_2| \le l \le l_1 + l_2
$$

の $l$ を持つ量が得られます [Batzner 2022]。
これは、角運動量 $l_1$ と $l_2$ を合成したときに取りうる全角運動量の規則と同じです。
組み合わせるときの係数も、角運動量の合成と同じ Clebsch–Gordan 係数です。

いちばん簡単な例は、2 つのベクトル（$l = 1$）$\mathbf a$、$\mathbf b$ のテンソル積です。
$1 \otimes 1$ からは $l = 0, 1, 2$ が得られます。
デカルト座標で書くと、それぞれ次の量に当たります。

- $l = 0$：内積 $\mathbf a \cdot \mathbf b$（1 成分）
- $l = 1$：外積 $\mathbf a \times \mathbf b$（3 成分）
- $l = 2$：$\frac{1}{2}(\mathbf a\mathbf b^\mathsf T + \mathbf b\mathbf a^\mathsf T) - \frac{1}{3}(\mathbf a\cdot\mathbf b)\mathsf I$（5 成分）

合わせて $1 + 3 + 5 = 9$ 成分で、$\mathbf a\mathbf b^\mathsf T$ の 9 成分をちょうど分けたものです。
2.2 節の $\mathbf v \cdot \mathbf v$ は、このうちの $l = 0$ の部分でした。

### 3.3 計算例：テンソル積が等変であることを確かめる

ランダムな 2 つのベクトルとランダムな回転で、3 つの量が正しく変わることを確かめます。
最後の行では、反転（すべての座標の符号を変える操作）も調べます。

```python
import numpy as np
from scipy.spatial.transform import Rotation

rng = np.random.default_rng(0)
a, b = rng.normal(size=3), rng.normal(size=3)        # 2 つの l = 1 の量（ベクトル）
Q = Rotation.random(random_state=2).as_matrix()      # ランダムな回転行列

def couple(a, b):
    """1 ⊗ 1 を l = 0, 1, 2 に分ける"""
    l0 = a @ b                                       # 内積（1 成分）
    l1 = np.cross(a, b)                              # 外積（3 成分）
    l2 = 0.5 * (np.outer(a, b) + np.outer(b, a)) - (a @ b) / 3 * np.eye(3)  # 対称でトレース 0（独立な成分は 5 個）
    return l0, l1, l2

l0, l1, l2 = couple(a, b)
m0, m1, m2 = couple(Q @ a, Q @ b)                    # 先に a, b を回してから組み合わせる
print("l=0：回したあと − 回す前               ", abs(m0 - l0))
print("l=1：回したあと − Q×(回す前)           ", np.abs(m1 - Q @ l1).max())
print("l=2：回したあと − Q (回す前) Q^T       ", np.abs(m2 - Q @ l2 @ Q.T).max())
n0, n1, n2 = couple(-a, -b)                          # 反転（座標の符号を変える）
print("反転したとき l=0, 1, 2 は変わらないか   ", abs(n0 - l0), np.abs(n1 - l1).max(), np.abs(n2 - l2).max())
```

```text
l=0：回したあと − 回す前                1.6653345369377348e-16
l=1：回したあと − Q×(回す前)            5.551115123125783e-17
l=2：回したあと − Q (回す前) Q^T        2.7755575615628914e-17
反転したとき l=0, 1, 2 は変わらないか    0.0 0.0 0.0
```

回してから組み合わせても、組み合わせてから回しても、同じ結果になりました（違いは $10^{-16}$ 程度の丸め誤差です）。
これが「テンソル積は等変な量から等変な量を作る」ということの意味です。

反転では、3 つとも変わりませんでした。
ベクトル $\mathbf a, \mathbf b$ は反転で符号が変わる（奇のパリティ）のに、外積は変わらない（偶のパリティ）のです。
したがって、回転だけでなく反転まで正しく扱うには、$l$ に加えてパリティ $p = \pm 1$ も区別する必要があります。
NequIP は、組み合わせる 2 つの量のパリティの積が、できる量のパリティになるという規則（$p_\text{出力} = p_1 p_2$）を守ってテンソル積を作ります [Batzner 2022]。
回転・反転・並進をすべて合わせた対称性の群を E(3) と呼びます。
NequIP の論文の題にある「E(3) 等変」は、これらすべてについて等変だという意味です。

**ここまでで分かったこと**：球面調和関数は向きの情報を $l$ ごとに分け、テンソル積は角運動量の合成と同じ規則で 2 つの等変な量から新しい等変な量を作ります。

## 4. NequIP：等変なメッセージパッシング

### 4.1 論文

NequIP（Neural Equivariant Interatomic Potentials）は、Batzner らが 2022 年に Nature Communications で発表したモデルです [Batzner 2022]。
最初の版は 2021 年に arXiv に公開されました。

### 4.2 モデルの流れ

NequIP の計算は、第 4 回の SchNet と同じく、原子ごとのベクトルをメッセージパッシングで更新していく形です [Batzner 2022]。
違うのは、各原子の特徴が、スカラー（$l = 0$）だけでなく、ベクトル（$l = 1$）や高い次数のテンソル（$l = 2, \dots$）の組になっていることです。

1. **初期の特徴**：元素から、$l = 0$ の特徴を作ります。
2. **相互作用ブロック**：原子 $i$ の特徴を、カットオフ半径の中の原子 $j$ からのメッセージで更新します。メッセージは、次の 2 つのテンソル積です。
    - フィルター：距離の関数 $R(r_{ij})$ と、向きの球面調和関数 $Y_{lm}(\hat{\mathbf r}_{ij})$ の積。$R$ は、距離を基底関数で展開したものを小さなニューラルネットワークに通して作ります。
    - 原子 $j$ の特徴。
3. **出力**：最後の $l = 0$ の特徴から原子エネルギーを作り、和を取って全エネルギーにします。力は、エネルギーを座標で微分して求めます。

テンソル積は、Thomas らの Tensor Field Networks と同じく、Clebsch–Gordan 係数を使って計算します [Thomas 2018]。
テンソル積では、上限 $l_\text{max}$ を超える $l$ は捨てます [Batzner 2022]。
フィルターと特徴の両方を $l = 0$ に限ると、SchNet [Schütt 2018] のような不変なモデルに戻ることが、論文でも述べられています [Batzner 2022]。
つまり NequIP は、SchNet の「距離のフィルター」を「距離と向きのフィルター」に、「スカラーの特徴」を「テンソルの特徴」に広げたものと見ることができます。

フィルターに $Y_{lm}(\hat{\mathbf r}_{ij})$ が入っているので、原子 $j$ がどの向きにあるかの情報が、メッセージに残ります。
2.1 節で見たように、この向きの情報が、あとのテンソル積で角度などの情報に変わります。

**ここまでで分かったこと**：NequIP は、距離と向き（球面調和関数）からなるフィルターと、テンソルの特徴をテンソル積で組み合わせて、等変なメッセージパッシングを行います。

## 5. MACE：多体のメッセージ

### 5.1 2 体のメッセージの限界

第 4 回で見たように、多くのメッセージパッシングのモデルでは、メッセージは中心の原子 $i$ と相手の原子 $j$ の 2 つで決まります（2 体のメッセージ）。
3 体以上の関係（角度や二面角など）は、更新をくり返したり、非線形の関数を通したりすることで、間接的に入ります。
MACE の論文は、そのために多くの更新（4〜6 回）が必要になり、計算が重く、受容野が広がって並列化が難しくなっていたと指摘しています [Batatia 2022]。

### 5.2 先に和を取り、あとで掛け合わせる

MACE（Batatia らが 2022 年に NeurIPS の会議で発表）は、1 回のメッセージで 3 体以上の関係を直接扱います [Batatia 2022]。
その方法は、2.2 節で見た「先に和を取り、あとで掛け合わせる」の一般化です。

1. まず、まわりの原子について、距離の関数と球面調和関数と相手の特徴の積を足します。これは 2 体の量の和なので、計算の手間は 2 体のメッセージと同じです。論文ではこれを $A_i$ と書いています。
2. 次に、$A_i$ どうしのテンソル積を取ります。$A_i$ を $\nu$ 個掛け合わせると、まわりの原子 $\nu$ 個の組についての和に相当する量ができます。中心の原子を合わせると $(\nu + 1)$ 体の量です。
3. この量の線形結合をメッセージにします。

$\nu$ を相関の次数（correlation order）と呼びます。MACE の論文の多くの実験では $\nu = 3$、つまり 4 体のメッセージを使っています [Batatia 2022]。
原子の組を 1 つずつ数え上げると、組の数は近くの原子の数の $\nu$ 乗で増えます。
先に和を取ってから掛け合わせれば、この数え上げを避けられます [Batatia 2022]。

この考え方は、Drautz の原子クラスター展開（atomic cluster expansion、ACE）から来ています [Drautz 2019]。
MACE の論文は、ACE が、多体の基底関数を、基底関数 1 つあたり体の数によらない一定の手間で作る系統的な枠組みであり、原子中心対称関数や SOAP などの多くの記述子をその特別な場合として含むと説明しています [Batatia 2022]。

### 5.3 何が示されたか

MACE の論文は、4 体のメッセージを使うと、メッセージパッシングの回数が 2 回で済むことを示しました [Batatia 2022]。
3BPA という分子のベンチマークでは、2 体のメッセージのモデルは精度が収束するまでに最大 5 回の更新を必要としたのに対し、MACE は 2 回で収束したと報告しています [Batatia 2022]。
更新の回数が少ないので、受容野も狭く、計算も速くなります。

**ここまでで分かったこと**：MACE は、まわりの原子についての和を先に取り、そのテンソル積で 4 体のメッセージを作ります。そのため、2 回の更新で高い精度が得られます。

## 6. データ効率がよくなった理由

### 6.1 原論文の主張

NequIP の論文は、要旨で次のように主張しています [Batzner 2022]。

- 等変な畳み込みによって、原子環境のより情報量の多い、忠実な表現が得られる。
- 既存のモデルより最大で 3 桁少ない学習データで、それらを上回る精度が得られる。

本文には、具体的な例が 2 つあります。
1 つは水と氷のデータで、NequIP を 133 個の構造で学習したモデルが、133,500 個の構造で学習した DeepMD のモデルを、力の誤差ですべての部分について上回ったという結果です [Batzner 2022]。
もう 1 つは、小さな分子のデータ（revised MD17）で回転の次数 $l$ の上限を 0, 1, 2, 3 と変えた比較で、$l = 0$（不変なモデル）から $l = 1$ への改善が特に大きく、論文はこれを等変性が精度に決定的な役割を果たしている証拠としています [Batzner 2022]。

データ効率がよいことは、高い精度の量子化学計算を学習データに使うときに役に立ちます。
NequIP の論文は、CCSD(T)（アスピリンだけは CCSD）で計算した分子のデータで、学習と検証に合わせて 1000 個の構造を使った結果を報告しています [Batzner 2022]。
第 1 回で見たように、モデルの精度の上限は学習データの手法で決まります。
少ないデータで済めば、計算の重い高精度の手法でも学習データを用意しやすくなり、その結果として精度の上限を上げられます。

### 6.2 学習曲線の傾き

学習データの数 $n$ と誤差の関係を両対数のグラフに描いたものを、学習曲線と呼びます。
多くの場合、誤差はおおよそ $n^{-a}$ のように減り、グラフは直線になります。
データ効率がよいとは、同じ誤差に少ないデータで届くことです。
それには、直線全体が下に平行移動する場合と、傾き $a$ が大きくなる場合があります。

MACE の論文は、NequIP の研究が、等変な特徴を入れると学習曲線の傾きが大きくなることを示したと紹介しています [Batatia 2022]。
そのうえで MACE の論文は、アスピリン分子のデータ（rMD17）で、2 回の更新の MACE を使って次の実験を報告しています [Batatia 2022]。

- 不変なメッセージだけでも、相関の次数 $\nu$ を 1, 2, 3 と上げると、傾きが大きくなった。
- $\nu = 3$ に固定して、等変なメッセージ（$l \ge 1$）を加えると、学習曲線は平行移動したが、傾きはほとんど変わらなかった。
- $\nu = 1$（2 体のメッセージ）に固定して等変なメッセージを加えても、傾きの変化はわずかだった。論文は、これを 2 回の更新で $\nu = 1$ に限ったモデルの表現力が低いためかもしれないと述べています。

### 6.3 分かっていることと、分かっていないこと

ここまでの結果をまとめます。

- 分かっていること：等変な特徴や多体のメッセージを使うモデルが、論文で使われたベンチマークで、不変な 2 体のメッセージのモデルより少ないデータで高い精度を出すこと。原子環境の向きの情報（2 節）と、多体の情報（5 節）が、そのために役立っていること。
- 分かっていないこと：学習曲線の傾きを決めるのが、等変性なのか、多体の情報なのか、その両方なのか。NequIP の論文では等変な特徴で傾きが大きくなり、MACE の論文の実験では、等変なメッセージを加えても傾きはほとんど変わりませんでした（6.2 節）。どちらも特定のモデルとデータセット（主に小さな分子や水）での結果で、ここで挙げた論文からは、一般にどちらが成り立つかは決められません。学習曲線の傾きの値そのものも、経験的に測ったものです。

また、NequIP と MACE も、カットオフ半径とメッセージパッシングの受容野の中の原子しか見ない、局所的なモデルです。
第 3 回で扱った長距離の静電相互作用の問題は、等変なモデルでもそのまま残ります。

**ここまでで分かったこと**：NequIP は等変な特徴で、MACE はさらに多体のメッセージで、データ効率を高めました。その理由の内訳（等変性と多体の情報がそれぞれどれだけ効くか）は、まだはっきりしていません。

## まとめ

- 不変は回しても変わらない量、等変は回すと決まった規則で一緒に変わる量です。エネルギーの出力は不変でも、モデルの途中の量は等変にできます。
- 向きを持つ量のまま足して、あとで組み合わせると、距離だけでは分からない角度などの情報が得られます。
- 球面調和関数は向きを $l$ ごとに分け、テンソル積は角運動量の合成と同じ規則で等変な量を組み合わせます。
- NequIP は等変なメッセージパッシングで、MACE は 4 体のメッセージで、少ないデータで高い精度を示しました。どちらも局所的なモデルで、長距離の問題は残ります。
