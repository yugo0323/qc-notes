## 1. 座標をそのまま入力にできない理由

### 1.1 デカルト座標の 3 つの問題

第 1 回で見たように、作りたいのは原子の種類と位置からエネルギーを返す関数です。
いちばん素直な入力は、原子のデカルト座標を順に並べた $3N$ 個の数です。
しかし、この入力には 3 つの問題があります。

1. **並進と回転**：分子全体を動かしたり回したりすると、座標はすべて変わります。しかし、エネルギーは変わりません。
2. **原子の番号の付け方**：水分子の 2 つの H 原子のどちらを 1 番にしても、同じ分子です。しかし、座標の並びは変わります。
3. **原子の数**：分子によって原子の数が違うので、入力の長さがそろいません。

1 と 2 の問題は、モデルの答えが「分子の置き方」や「番号の付け方」に左右されることを意味します。
データをたくさん集めれば、モデルがこれらを学ぶかもしれません。
しかし、それには余分なデータが要り、しかも答えが厳密に同じになる保証はありません。

### 1.2 記述子が満たすべき条件

そこで、座標をいったん別の数の並びに直してから、モデルに渡します。
この数の並びを記述子（descriptor）、または表現（representation）と呼びます。
エネルギーを予測するための記述子には、次の条件が求められます [Bartók 2013]。

- **並進の不変性**：分子全体を平行移動しても、記述子が変わらない。
- **回転の不変性**：分子全体を回転しても、記述子が変わらない。鏡に映す操作（反転）についても同じ。
- **置換の不変性**：同じ元素の原子の番号を入れ替えても、記述子が変わらない。
- **滑らかさ**：原子を少し動かしたとき、記述子も少しだけ、滑らかに変わる。力を求めるには、記述子を座標で微分する必要があるからです。

もう 1 つ、望ましい条件があります。
違う構造は、違う記述子になることです。
2 つの違う構造が同じ記述子になると、モデルはその 2 つに同じエネルギーを返すしかありません。

なお、ここで「不変」が求められるのは、予測したいものがエネルギーのように回転で変わらない量だからです。
双極子モーメントのように回転で向きが変わる量を予測するときの考え方は、第 5 回で扱います。

**ここまでで分かったこと**：記述子は、並進・回転・置換で変わらず、原子の動きに対して滑らかでなければなりません。

## 2. Coulomb 行列：分子全体を 1 つの行列で表す

### 2.1 定義

Rupp らは 2012 年に、分子を次の行列 $\mathsf M$ で表しました [Rupp 2012]。
原子 $I$ の原子番号を $Z_I$、位置を $\mathbf R_I$ とします。

$$
M_{IJ} =
\begin{cases}
0.5\, Z_I^{2.4} & (I = J) \\[4pt]
\dfrac{Z_I Z_J}{|\mathbf R_I - \mathbf R_J|} & (I \neq J)
\end{cases}
$$

非対角要素は、原子核 $I$ と $J$ のクーロン反発エネルギー（原子単位）です。
対角要素は、孤立原子のエネルギーを原子番号の多項式で近似したものだと説明されています [Rupp 2012]。
この記述子は Coulomb 行列（Coulomb matrix）と呼ばれます。

非対角要素は原子間の距離だけで決まるので、Coulomb 行列は並進と回転で変わりません。
しかし、原子の番号を入れ替えると、行と列の順番が入れ替わります。
これを計算で確かめます。

### 2.2 計算例：回転では変わらず、番号の入れ替えで変わる

水分子で Coulomb 行列を作ります。
距離は bohr に直してから使います。

```python
import numpy as np
from scipy.spatial.transform import Rotation

# 水分子（Å）。原子番号と座標
Z = np.array([8, 1, 1])
R = np.array([[0.0000,  0.0000,  0.1173],
              [0.0000,  0.7572, -0.4692],
              [0.0000, -0.7572, -0.4692]]) / 0.529177   # bohr に直す

def coulomb_matrix(Z, R):
    n = len(Z)
    M = np.empty((n, n))
    for i in range(n):
        for j in range(n):
            if i == j:
                M[i, j] = 0.5 * Z[i] ** 2.4
            else:
                M[i, j] = Z[i] * Z[j] / np.linalg.norm(R[i] - R[j])
    return M

np.set_printoptions(precision=3, suppress=True)
M = coulomb_matrix(Z, R)
print("元の Coulomb 行列\n", M)

# 1) 回転と並進
Q = Rotation.random(random_state=0).as_matrix()
R_rot = R @ Q.T + np.array([1.0, -2.0, 0.5])
print("回転・並進後との差の最大値:", np.abs(coulomb_matrix(Z, R_rot) - M).max())

# 2) 原子の順番を入れ替える（H, O, H の順にする）
p = [1, 0, 2]
M_perm = coulomb_matrix(Z[p], R[p])
print("順番を変えた Coulomb 行列\n", M_perm)
print("元の行列との差の最大値:", np.abs(M_perm - M).max())

# 3) 固有値にする
ev = np.sort(np.linalg.eigvalsh(M))[::-1]
ev_perm = np.sort(np.linalg.eigvalsh(M_perm))[::-1]
print("固有値（元）       :", ev)
print("固有値（順番を変更）:", ev_perm)
```

```text
元の Coulomb 行列
 [[73.517  4.42   4.42 ]
 [ 4.42   0.5    0.349]
 [ 4.42   0.349  0.5  ]]
回転・並進後との差の最大値: 8.881784197001252e-16
順番を変えた Coulomb 行列
 [[ 0.5    4.42   0.349]
 [ 4.42  73.517  4.42 ]
 [ 0.349  4.42   0.5  ]]
元の行列との差の最大値: 73.01669471981023
固有値（元）       : [74.05   0.316  0.151]
固有値（順番を変更）: [74.05   0.316  0.151]
```

回転と並進のあとの違いは $10^{-16}$ 程度で、計算機の丸め誤差です。
一方、O を 2 番目に置くと、行列の要素の位置が変わり、要素ごとの差は 73 にもなります。
行列をそのまま数の並びとしてモデルに渡すと、同じ分子が別の入力になってしまいます。

### 2.3 固有値にすると置換で変わらない

番号の入れ替えは、行列 $\mathsf M$ を $\mathsf P \mathsf M \mathsf P^\mathsf T$ に変えます。
$\mathsf P$ は、単位行列の行を並べ替えた置換行列です。
$\mathsf P$ は直交行列なので、$\mathsf P \mathsf M \mathsf P^\mathsf T$ と $\mathsf M$ の固有値は同じです。
上の出力の最後の 2 行が、それを示しています。

Rupp らは、固有値を絶対値の大きい順に並べたものを分子の記述子として使いました [Rupp 2012]。
原子の数が違う分子どうしは、少ない方の固有値の後ろに 0 を足して長さをそろえます。
この記述子とカーネル法を組み合わせ、7000 個あまりの有機分子の原子化エネルギーを、混成汎関数の値に対して平均絶対誤差約 10 kcal/mol で予測しています [Rupp 2012]。

### 2.4 固有値の記述子の限界

固有値にすると、失われる情報があります。
$N$ 原子の分子では、固有値は $N$ 個です。
一方、構造を決める内部座標は $3N-6$ 個あります。
$N \ge 4$ では $3N-6 > N$ なので、固有値だけから構造を一意に復元することはできません。

もう 1 つの問題は滑らかさです。
固有値を大きさの順に並べると、2 つの固有値の大小が入れ替わるところで、並べた結果の微分が不連続になります。
並べ替えで置換の不変性を得る方法には、一般にこの問題があります [Musil 2021]。

さらに、Coulomb 行列は分子全体を 1 つの記述子で表します。
そのため、学習に使った分子より大きな分子への応用が難しくなります。
この点を解決するのが、次の節の「原子ごとの記述子」です。

**ここまでで分かったこと**：Coulomb 行列は並進・回転で変わらず、固有値にすると置換でも変わりません。ただし、情報が失われること、分子全体を 1 つで表すことが弱点です。

## 3. 原子中心対称関数：原子のまわりの環境を表す

### 3.1 原子環境という考え方

化学では、ある原子の性質は、主にそのまわりの原子で決まると考えます。
たとえば C–H 結合の性質は、遠く離れた官能基にはあまりよりません。
そこで、原子 $i$ を中心に、半径 $R_\mathrm c$ の球の中にある原子だけを見て、原子 $i$ の「環境」を数の並びで表します。
$R_\mathrm c$ をカットオフ半径（cutoff radius）と呼びます。

原子ごとに記述子を作る方法は、Behler と Parrinello の 2007 年の論文で導入されました [Behler 2007]。
Behler は 2011 年の論文で、その関数（原子中心対称関数、atom-centered symmetry functions、ACSF）の性質を詳しく調べています [Behler 2011]。
ここでいう「対称」は、並進・回転・置換で変わらないという意味です。

### 3.2 カットオフ関数

球の外の原子を急に切り捨てると、原子が球の境界を出入りするときに記述子が飛びます。
そこで、距離 $R_\mathrm c$ で滑らかに 0 になる関数をかけます。
よく使われるのは次の余弦型のカットオフ関数です。

$$
f_\mathrm c(R) =
\begin{cases}
\dfrac{1}{2}\left[\cos\left(\dfrac{\pi R}{R_\mathrm c}\right) + 1\right] & (R \le R_\mathrm c) \\[6pt]
0 & (R > R_\mathrm c)
\end{cases}
$$

$R = R_\mathrm c$ で、関数の値も 1 階微分も 0 になります。
そのため、力（記述子の微分を含む）も境界で飛びません。

### 3.3 動径の関数と角度の関数

原子 $i$ と $j$ の距離を $R_{ij}$ とします。
動径の対称関数は、まわりの原子についての和です。

$$
G_i^{\text{動径}} = \sum_{j \neq i} e^{-\eta (R_{ij} - R_\mathrm s)^2} f_\mathrm c(R_{ij}).
$$

$\eta$ はガウス関数の幅、$R_\mathrm s$ は中心の位置を決める数で、使う人が選びます。
これは「原子 $i$ から距離 $R_\mathrm s$ 付近に、原子がどれだけあるか」を数える量です。
$\eta$ と $R_\mathrm s$ の組を何通りも用意すると、まわりの原子の距離の分布を何段階もの分解能で調べられます。

距離だけでは、結合角の違いが分かりません。
そこで、原子 $i$ を頂点とする角度 $\theta_{ijk}$ を使う関数も加えます。

$$
G_i^{\text{角度}} = 2^{1-\zeta} \sum_{j \neq i} \sum_{k \neq i, j}
\left(1 + \lambda \cos\theta_{ijk}\right)^{\zeta}
e^{-\eta (R_{ij}^2 + R_{ik}^2 + R_{jk}^2)}
f_\mathrm c(R_{ij})\, f_\mathrm c(R_{ik})\, f_\mathrm c(R_{jk}).
$$

この 2 つは、Behler の 2011 年の論文の記号では $G^2$ と $G^4$ と呼ばれる関数です [Behler 2011]。
$\lambda$ は $+1$ か $-1$ で、角度の分布のどちら側（0° 側か 180° 側か）を強く見るかを決めます。
$\zeta$ は、角度についての分解能を決めます。

どちらの関数も、距離と角度だけで決まるので、並進と回転で変わりません。
まわりの原子についての和なので、まわりの原子の番号の付け方にもよりません。
ただし、この和は元素ごとに分けて取ります。
「まわりの H についての和」と「まわりの O についての和」を別の成分にすれば、相手の元素を区別できます。

### 3.4 計算例：原子ごとの記述子

水分子の各原子について、動径の対称関数を作ります。
$R_\mathrm s = 0$、$\eta = 0.5, 2.0$ Å$^{-2}$、$R_\mathrm c = 6$ Å とし、相手が H の和と O の和を分けて 4 成分にします。

```python
import numpy as np
from scipy.spatial.transform import Rotation

Z = np.array([8, 1, 1])
R = np.array([[0.0000,  0.0000,  0.1173],
              [0.0000,  0.7572, -0.4692],
              [0.0000, -0.7572, -0.4692]])   # Å

def fc(r, rc=6.0):
    """余弦型のカットオフ関数"""
    return np.where(r <= rc, 0.5 * (np.cos(np.pi * r / rc) + 1.0), 0.0)

def g2(Z, R, eta_list=(0.5, 2.0), rs=0.0, rc=6.0):
    """原子ごとの動径対称関数。相手が H か O かで分けて並べる"""
    n = len(Z)
    G = []
    for i in range(n):
        row = []
        for elem in (1, 8):
            for eta in eta_list:
                s = 0.0
                for j in range(n):
                    if j != i and Z[j] == elem:
                        r = np.linalg.norm(R[i] - R[j])
                        s += np.exp(-eta * (r - rs) ** 2) * fc(r, rc)
                row.append(s)
        G.append(row)
    return np.array(G)

np.set_printoptions(precision=4, suppress=True)
G = g2(Z, R)
print("原子ごとの記述子（行：O, H, H）\n", G)
Q = Rotation.random(random_state=1).as_matrix()
p = [2, 0, 1]                               # 順番を H, O, H に変える
G_new = g2(Z[p], R[p] @ Q.T + 3.0)
print("回転・並進・入れ替え後（行：H, O, H）\n", G_new)
print("元の行を同じ順に並べた差:", np.abs(G_new - G[p]).max())
```

```text
原子ごとの記述子（行：O, H, H）
 [[1.1864 0.2997 0.     0.    ]
 [0.2703 0.0087 0.5932 0.1498]
 [0.2703 0.0087 0.5932 0.1498]]
回転・並進・入れ替え後（行：H, O, H）
 [[0.2703 0.0087 0.5932 0.1498]
 [1.1864 0.2997 0.     0.    ]
 [0.2703 0.0087 0.5932 0.1498]]
元の行を同じ順に並べた差: 1.1102230246251565e-16
```

各行が 1 つの原子の記述子です。
O の行の後半 2 成分が 0 なのは、O のまわりに O がないからです。
2 つの H は対称な位置にあるので、同じ記述子になります。

回転・並進・番号の入れ替えのあと、行の順番は入れ替わりました。
しかし、各原子の記述子そのものは変わっていません。
原子ごとの記述子は、原子と一緒に並べ替わるだけです。
これを「置換について等変」と言います。
第 3 回で見るように、原子ごとの寄与を足し合わせると、和は並べ替えで変わらなくなり、置換の不変性が完成します。

**ここまでで分かったこと**：原子中心対称関数は、カットオフ半径の中の原子の距離と角度から、原子ごとの記述子を作ります。並進と回転で変わらず、番号の入れ替えでは原子と一緒に並べ替わるだけです。

## 4. SOAP：まわりの原子の密度を比べる

### 4.1 原子の密度で環境を表す

原子中心対称関数では、$\eta$、$R_\mathrm s$、$\zeta$ などの組を、使う人が経験で選ぶ必要がありました。
Bartók、Kondor、Csányi は 2013 年に、この選択を減らす方法を提案しました [Bartók 2013]。
それが SOAP（Smooth Overlap of Atomic Positions）です。

SOAP では、原子 $i$ のまわりの原子を、ぼかした密度で表します。

$$
\rho_i(\mathbf r) = \sum_{j} \exp\!\left(-\frac{|\mathbf r - \mathbf r_{ij}|^2}{2\sigma^2}\right).
$$

$\mathbf r_{ij} = \mathbf R_j - \mathbf R_i$ は、中心の原子から原子 $j$ へのベクトルです。
$\sigma$ はぼかしの幅です。
つまり、まわりの原子 1 つ 1 つの位置にガウス関数を置いて足したものです。
和はカットオフ半径の中の原子について取ります（実際の計算では、境界で滑らかに 0 になるようにします）。

### 4.2 2 つの環境の重なりを、あらゆる向きで平均する

2 つの原子環境 $\rho$ と $\rho'$ がどれだけ似ているかは、2 つの密度の重なり積分 $\int \rho(\mathbf r)\rho'(\mathbf r)\,d\mathbf r$ で測れそうです。
ただし、この積分は $\rho'$ の向きによって変わります。
そこで、$\rho'$ をあらゆる向きに回して重なり積分を計算し、その 2 乗を平均します。
平均したものは向きによらないので、回転で変わらない「似ている度合い」になります。
これが SOAP のカーネル（2 つの入力の似ている度合いを表す関数）の考え方です [Bartók 2013]。

### 4.3 パワースペクトルとの関係

この回転平均は、実際には積分しなくても計算できます。
密度 $\rho_i$ を、動径の関数 $g_n(r)$ と球面調和関数 $Y_{lm}(\hat{\mathbf r})$ の積で展開します。

$$
\rho_i(\mathbf r) = \sum_{n,l,m} c^{(i)}_{nlm}\, g_n(r)\, Y_{lm}(\hat{\mathbf r}).
$$

$r = |\mathbf r|$、$\hat{\mathbf r} = \mathbf r / r$ です。
球面調和関数は、水素原子の軌道の角度部分（s, p, d, … の形）と同じ関数です。
係数から、次の量（パワースペクトル）を作ります。

$$
p^{(i)}_{nn'l} = \sum_{m=-l}^{l} c^{(i)}_{nlm} \left(c^{(i)}_{n'lm}\right)^{*}.
$$

$m$ について和を取ると、回転で変わらない量になります。
回転は、同じ $l$ の $2l+1$ 個の係数を互いに混ぜるだけで、その「長さ」を変えないからです。
Bartók らは、前の段落の回転平均した重なりの 2 乗が、パワースペクトルどうしの内積に等しいことを示しました [Bartók 2013]。
つまり SOAP は、パワースペクトルを記述子にした方法と見ることもできます。

$p_{nn'l}$ は、中心の原子と、まわりの 2 つの原子の関係（2 つの距離と、その間の角度）を表す量です。
その意味では、原子中心対称関数の角度の関数と同じ種類の情報を持っています。
実際、基底を十分に大きくした極限では、原子中心対称関数は密度の展開係数から作り直せることが示されています [Musil 2021]。
ばらばらに見えた記述子が、「まわりの原子の密度」という共通の考え方でつながるのです。

### 4.4 距離と角度だけでは足りないことがある

距離と角度（中心の原子とまわりの 2 原子）だけを使う記述子では、違う原子環境が同じ記述子になる例があることが示されています [Pozdnyakov 2020]。
同じ論文は、中心の原子とまわりの 3 原子の関係まで使っても、そうした例が残ることを示しています。
エネルギーを原子ごとの寄与の和で表すと影響は弱まりますが、なくなりはしないとも述べています [Pozdnyakov 2020]。
これは、1.2 節の「違う構造は違う記述子になる」という条件が、厳密には満たされないことを意味します。
この問題は、第 5 回の等変なモデルを理解するときの手がかりになります。

**ここまでで分かったこと**：SOAP は、まわりの原子の密度の重なりを回転で平均して環境を比べます。それはパワースペクトルの内積と同じで、原子中心対称関数とも同じ種類の情報を持っています。

## 5. カットオフ半径の選び方

原子ごとの記述子では、カットオフ半径 $R_\mathrm c$ の外の原子は見えません。
$R_\mathrm c$ の選び方は、精度と速さの釣り合いで決まります。

- $R_\mathrm c$ を大きくすると、遠くの原子の影響まで取り込めます。しかし、球の中の原子の数は $R_\mathrm c^3$ に比例して増えるので、計算が重くなります。角度の関数では原子の組の数が効くので、さらに重くなります。
- $R_\mathrm c$ を小さくすると速くなりますが、球の外からの影響は、どれだけ学習データを増やしても再現できません。

実際の値の例を挙げます。
ANI-1 は、動径の関数に 4.6 Å、角度の関数に 3.1 Å のカットオフ半径を使っています [Smith 2017]。
論文は、この値を原子間距離の分布から選んだと説明しています。
角度の関数の方を短くしたのは、角度の環境は学習データの中で距離ほど十分には現れない、と見込んだためです。
この選び方は、試した結果でも確かめたと述べられています [Smith 2017]。

カットオフ半径を決めた時点で、モデルは「$R_\mathrm c$ より遠くの原子は、その原子のエネルギーに影響しない」と仮定したことになります。
分子の中の共有結合だけを考えるなら、この仮定は多くの場合よく成り立ちます。
しかし、イオンや極性分子の静電相互作用は、距離の 1 乗や 3 乗に反比例してゆっくりとしか弱まりません。
この「局所性」の仮定とその限界は、第 3 回で詳しく扱います。

**ここまでで分かったこと**：カットオフ半径は精度と速さの釣り合いで選びます。その外の影響は、モデルには見えません。

## まとめ

- 記述子は、並進・回転・置換で変わらず、原子の動きに対して滑らかでなければなりません。
- Coulomb 行列は回転で変わりませんが、原子の番号の付け方で変わります。固有値にすると置換で変わらなくなりますが、情報が失われます。
- 原子中心対称関数と SOAP は、カットオフ半径の中の原子から原子ごとの記述子を作ります。どちらも「まわりの原子の密度」という共通の考え方で理解できます。
- カットオフ半径より遠くの原子は、モデルには見えません。
