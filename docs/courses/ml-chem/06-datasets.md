# 第 6 回　データセット：どの理論の値を学習しているか

!!! abstract "この回の道筋"
    機械学習ポテンシャルの性質の多くは、モデルの形よりも、学習に使ったデータセットで決まります。この回では、代表的なデータセットを「理論レベル、構造の選び方、元素、電荷とスピン多重度」の 4 つの問いで読み比べます。そのうえで、汎関数の誤差がモデルにそのまま入ること、データの分布の外ではモデルを信用できないことを、計算例と文献の数値で確かめます。

    | 節 | 内容 |
    |---|---|
    | 1 | データセットを読むための 4 つの問い |
    | 2 | 代表的なデータセット |
    | 3 | 汎関数の誤差は、モデルにそのまま入る |
    | 4 | データの分布の外では、モデルを信用できない |
    | 5 | 理論レベルの違うデータを混ぜるとき |

    **前に読んでおく回**：[第 1 回](01-what-to-learn.md)、[第 4 回](04-early-mlips.md)

!!! tip "物理的なイメージ"
    データセットが決めているのは、モデルが真似る「お手本」と、真似できる「範囲」です。モデルは学習データの理論レベルの答えを真似るだけなので、お手本の汎関数の誤差は、そのままモデルに入ります。また、学習データにない種類の構造（元素、電荷、スピン、大きくひずんだ構造）では、モデルはお手本を見ていないので、信用できません。

## 1. データセットを読むための 4 つの問い

第 1 回の 5 節で、モデルの精度の上限は、学習データを作った手法の精度で決まることを見ました。
では、実際のデータセットは、どの手法で作られているのでしょうか。
この回では、データセットを次の 4 つの問いで読みます。

1. **理論レベル**：どの手法（汎関数と基底関数）で計算したか。
2. **構造の選び方**：エネルギー最小の構造だけか、ずらした構造も含むか、反応の経路上の構造も含むか。
3. **元素**：どの元素を含むか。
4. **電荷とスピン多重度**：中性の閉殻分子だけか、イオンや開殻の系も含むか。

1 つ目は、モデルの精度の上限を決めます。
2〜4 つ目は、モデルを使ってよい範囲を決めます。
モデルは、学習データに出てこなかった種類の構造や元素について、正しい答えを出す保証がないからです。
規模（構造の数）も大事ですが、規模が大きくても、これら 4 つの問いの答えが目的に合っていなければ役に立ちません。

**ここまでで分かったこと**：データセットを使う前に、理論レベル、構造の選び方、元素、電荷とスピン多重度の 4 つを確かめます。

## 2. 代表的なデータセット

分子の機械学習でよく使われるデータセットを、発表の順に見ていきます。
数値は、それぞれの原論文から写したものです。

### 2.1 QM9（2014 年）：平衡構造の性質

QM9 は、GDB-17 という化合物のデータベースから、重原子（C、N、O、F）が 9 個以下の分子 133,885 個を集めたものです [Ramakrishnan 2014]。
元素は H、C、N、O、F です。
すべての分子について、B3LYP/6-31G(2df,p) で最適化した構造と、その構造での性質（双極子モーメント、分極率、原子化エネルギーなど）が入っています [Ramakrishnan 2014]。
一部の分子（C₇H₁₀O₂ の異性体 6,095 個）については、より精度の高い G4MP2 の原子化エネルギーもあります [Ramakrishnan 2014]。

QM9 の構造は、すべてエネルギー最小の構造です。
そのため、QM9 は「構造から性質を予測する」問題のベンチマークには向いています。
一方、ずらした構造を含まないので、分子動力学（MD）で使うポテンシャルの学習には向きません。
ANI-1x のデータの論文も、QM9 のような平衡構造だけのデータで学習したモデルは、DFT で最適化した構造でしか正確さが示されていない、と指摘しています [Smith 2020]。

### 2.2 ANI-1x と ANI-1ccx（2018〜2020 年）：ずらした構造と、結合クラスターのデータ

第 4 回で紹介した ANI-1 のデータは、基準振動に沿って構造をランダムにずらして作りました。
その後継の ANI-1x のデータセットは、約 500 万個の構造について、ωB97X/6-31G(d) でエネルギーと力を計算したものです [Smith 2020]。
元素は H、C、N、O の 4 つです。

ANI-1x の特徴は、構造の選び方です。
複数のモデル（アンサンブル）の予測のばらつきが大きい構造を、自動的に選んでデータに加えています [Smith 2018]。
このような選び方を能動学習（active learning）と呼びます。
詳しくは[第 10 回](10-cautions.md)で扱います。

ANI-1ccx のデータセットは、ANI-1x の構造から選んだ約 50 万個（約 1 割）について、CCSD(T)/CBS に近い値を計算し直したものです [Smith 2020]。
CBS は完全基底（complete basis set）の極限を表します。
実際の計算には、DLPNO-CCSD(T) という近似の結合クラスター法と、MP2 を使った基底関数の外挿を組み合わせた方法が使われています [Smith 2020]。
論文ではこれを CCSD(T)\*/CBS と書いています。

ANI-1x と ANI-1ccx に入っているのは中性の分子だけで、イオンは入っていません [Eastman 2023]。
AIQM1 の論文も、この 2 つのデータセットは「中性で閉殻の、基底状態の小さな分子」からなると説明しています [Zheng 2021]。

### 2.3 SPICE（2023 年）：薬の分子とタンパク質を目標にしたデータ

SPICE は、薬の候補になる小さな分子と、それが結合するタンパク質の MD を目標にしたデータセットです [Eastman 2023]。
最初の版には、110 万個を超える構造があります。
小さな分子、2 分子の組（二量体）、ジペプチド、水に囲まれたアミノ酸などの部分に分かれています [Eastman 2023]。
元素は 15 種類で、電荷をもつ分子も含みます。
理論レベルは ωB97M-D3(BJ)/def2-TZVPPD です [Eastman 2023]。
def2-TZVPPD の最後の D は、陰イオンを正しく扱うための広がった関数（diffuse function）が入っていることを表します。

論文は、この理論レベルを「計算の予算の中で実用的な、最も精度の高いもの」として選んだと説明しています。
さらに精度を上げるには、二重混成汎関数か 4 重ゼータの基底関数が必要で、どちらも計算がはるかに重くなる、とも書いています [Eastman 2023]。
また、SPICE は MD で現れる程度にエネルギーの高い構造は含みますが、共有結合ができたり切れたりする、さらにエネルギーの高い構造は意図的に除いています [Eastman 2023]。
つまり、SPICE で学習したモデルは、反応を扱うことを想定していません。

### 2.4 Transition1x（2022 年）：反応の経路の構造

Transition1x は、反応を扱うためのデータセットです [Schreiner 2022]。
有機分子の約 1 万個の反応について、反応物と生成物を結ぶ最小エネルギー経路を NEB 法（nudged elastic band、経路上の構造の列を少しずつ動かして最小エネルギー経路を探す方法）で求めました。
その途中で計算した構造をすべて保存し、960 万個の DFT の計算を集めています [Schreiner 2022]。
元素は H、C、N、O です。

理論レベルは ωB97X/6-31G(d) で、これは ANI-1x と同じです。
論文は、ANI-1x と組み合わせて使えるように、わざと同じ理論レベルを選んだと述べています [Schreiner 2022]。
この選択の意味は、5 節で考えます。

### 2.5 OMol25（2025 年）：元素、電荷、スピンを大きく広げたデータ

OMol25 は、Meta FAIR などのグループが 2025 年に公開したデータセットです [Levine 2025]。
要旨によれば、ωB97M-V/def2-TZVPD で計算した 1 億件を超える DFT の計算からなり、83 種類の元素を含み、最大で 350 原子の系を含みます [Levine 2025]。
計算には、合計で 66 億 CPU コア時間を使ったと書かれています [Levine 2025]。
扱う分野は、生体分子、金属錯体、電解質、主族元素の分子です。
SPICE、ANI-2x、Transition1x などの既存のデータセットの構造も、同じ理論レベルで計算し直して取り込んでいます [Levine 2025]。

OMol25 で特に新しいのは、電荷とスピン多重度の幅です。
本文によれば、電荷は −10 から +10 まで、スピン多重度は 1 から 11 までの系を含みます [Levine 2025]。
遷移金属錯体については、同じ錯体を高スピンと低スピンの両方で計算したものもあります [Levine 2025]。
開殻の系は非制限 Kohn–Sham 法（UKS）で計算されています [Levine 2025]。

ωB97M-V は、範囲分離混成メタ GGA と呼ばれる種類の汎関数です。
論文は、これを選んだ理由として、多くの研究で、幅広い問題について最も精度の高い汎関数の 1 つと示されていることを挙げています [Levine 2025]。
基底関数に広がった関数を含む def2-TZVPD を選んだのは、陰イオンを含むからです [Levine 2025]。

### 2.6 まとめの表

| データセット | 理論レベル | 規模 | 元素 | 構造の選び方 | 電荷とスピン |
|---|---|---|---|---|---|
| QM9 | B3LYP/6-31G(2df,p) | 約 13 万 4 千分子 | H, C, N, O, F | 平衡構造だけ | 中性 |
| ANI-1x | ωB97X/6-31G(d) | 約 500 万構造 | H, C, N, O | 能動学習でずらした構造 | 中性 |
| ANI-1ccx | CCSD(T)\*/CBS | 約 50 万構造 | H, C, N, O | ANI-1x から選んだもの | 中性 |
| SPICE | ωB97M-D3(BJ)/def2-TZVPPD | 110 万構造超 | 15 種類 | MD で現れる構造（反応は除く） | イオンを含む |
| Transition1x | ωB97X/6-31G(d) | 960 万計算 | H, C, N, O | 反応の経路（NEB） | 中性 |
| OMol25 | ωB97M-V/def2-TZVPD | 1 億計算超 | 83 種類 | 多様（反応、溶媒和、錯体など） | 電荷 −10〜+10、多重度 1〜11 |

表を縦に見ると、理論レベルが少しずつ変わってきたことが分かります。
B3LYP から ωB97X、さらに ωB97M 系の汎関数へと移り、基底関数も大きくなっています。
横に見ると、新しいデータセットほど、構造の選び方、元素、電荷とスピンの幅が広がっていることが分かります。

**ここまでで分かったこと**：代表的なデータセットは、理論レベル、構造の選び方、元素、電荷とスピンの範囲がそれぞれ違います。モデルを使う前に、そのモデルがどのデータセットで学習したかを確かめる必要があります。

## 3. 汎関数の誤差は、モデルにそのまま入る

### 3.1 計算例：H + H₂ の反応の障壁

2 節の表のデータセットは、ANI-1ccx を除いて、主な値をすべて DFT で計算しています。
DFT の値には、汎関数による誤差があります。
その誤差の大きさは、問題の種類によって違います。

例として、H + H₂ → H₂ + H という最も簡単な反応の障壁の高さを計算します。
電子が 3 個しかないので、この基底関数での厳密な値（FCI）が計算できます。
遷移状態の近くの構造として、3 つの H 原子が 0.930 Å 間隔で一直線に並んだ構造を使います。
H₂ の結合距離は 0.741 Å とし、どの手法でも同じ構造を使います（各手法で構造を最適化してはいません）。
障壁の高さは、$E(\mathrm{H_3}) - E(\mathrm{H_2}) - E(\mathrm H)$ で求めます。

```python
from pyscf import gto, scf, dft, fci

basis = "cc-pvtz"
geoms = {  # Å。H3 は直線で対称な構造（遷移状態の近く）
    "H":  ("H 0 0 0", 1),
    "H2": ("H 0 0 0; H 0 0 0.741", 0),
    "H3": ("H 0 0 -0.930; H 0 0 0; H 0 0 0.930", 1),
}

def energy(method, atom, spin):
    mol = gto.M(atom=atom, basis=basis, spin=spin, verbose=0)
    if method == "FCI":
        mf = scf.RHF(mol).run() if spin == 0 else scf.ROHF(mol).run()
        return fci.FCI(mf).kernel()[0]
    if method == "HF":
        return scf.UHF(mol).run().e_tot
    mf = dft.UKS(mol, xc=method)
    if method == "wb97m_v":
        mf.nlc = "vv10"
    return mf.run().e_tot

print("手法        障壁の高さ/(kcal/mol)")
for method in ["FCI", "HF", "pbe", "b3lyp", "wb97x", "wb97m_v"]:
    e = {k: energy(method, *v) for k, v in geoms.items()}
    barrier = (e["H3"] - e["H2"] - e["H"]) * 627.5
    print(f"{method:10s}  {barrier:6.1f}")
```

```text
手法        障壁の高さ/(kcal/mol)
FCI            9.9
HF            17.6
pbe            3.7
b3lyp          4.2
wb97x         10.8
wb97m_v        8.7
```

基底関数は cc-pVTZ で、どの手法も同じです。
FCI の 9.9 kcal/mol を正解とすると、手法によって誤差の大きさがまったく違います。
HF は障壁を 8 kcal/mol 近く高く見積もります。
PBE と B3LYP は、逆に障壁を半分以下に見積もります。
ωB97X と ωB97M-V の誤差は、この例では 1〜2 kcal/mol 程度です。

ここで、「完璧な機械学習ポテンシャル」を考えてみます。
B3LYP のデータで学習したモデルは、うまくいっても 4.2 kcal/mol という障壁を再現するだけです。
この誤差は、データをいくら増やしても、モデルをいくら良くしても消えません。
2 節の表で、新しいデータセットほど ωB97X や ωB97M 系の汎関数を使っているのは、このような汎関数の誤差を小さくするためです。
ただし、この例は 1 つの反応での比較です。
汎関数の良し悪しは、問題の種類ごとに、ベンチマークで確かめる必要があります。

### 3.2 文献の例：DFT の誤差をまねる ANI-1x

同じことは、実際のデータセットとモデルでも確かめられています。
ANI-1ccx の論文は、炭化水素の反応エネルギーのベンチマーク HC7/11 で、次の 4 つの誤差を比べています [Smith 2019]。

| 手法 | 平均絶対偏差 / 二乗平均平方根偏差（kcal/mol） |
|---|---|
| ωB97X/6-31G(d)（DFT そのもの） | 16.4 / 22.2 |
| ANI-1x（その DFT で学習） | 19.1 / 24.6 |
| ANI-1ccx（CCSD(T)\*/CBS で学習し直し） | 2.5 / 2.9 |
| CCSD(T)\*/CBS（学習データの手法そのもの） | 1.6 / 1.8 |

ANI-1x の誤差は、学習に使った DFT の誤差とほぼ同じ大きさです。
論文も、ANI-1x は DFT の振る舞いをよくまねている、と述べています [Smith 2019]。
学習データを CCSD(T)\*/CBS に変えた ANI-1ccx では、誤差が大きく下がります。
このように、モデルの誤差の大部分が学習データの手法から来ることがあります。
ANI-1ccx の学習の方法（転移学習）は、[第 8 回](08-delta-learning.md)で扱います。

**ここまでで分かったこと**：DFT のデータで学習したモデルは、その汎関数の誤差もまねます。汎関数の誤差が大きい問題では、モデルをいくら良くしても誤差は小さくなりません。

## 4. データの分布の外では、モデルを信用できない

### 4.1 構造の分布の外：遷移状態の例

第 1 回の式で、全体の誤差を「機械学習の誤差」と「参照の手法の誤差」に分けました。
3 節は 2 つ目の誤差の話でした。
この節では 1 つ目の誤差、とくに学習データと違う種類の構造での誤差を考えます。

Transition1x の論文は、同じモデル（PaiNN という等変なメッセージパッシングのモデル）を 3 つのデータセットで別々に学習し、反応の遷移状態の構造で試しています [Schreiner 2022]。
3 つのデータセットの理論レベルはそろえてあるので、違うのは構造の選び方だけです。
遷移状態でのエネルギーの平均絶対誤差は次のとおりです。

| 学習に使ったデータセット | 遷移状態でのエネルギーの平均絶対誤差（eV） |
|---|---|
| Transition1x（反応の経路） | 0.075 |
| ANI-1x（ずらした構造） | 0.495 |
| QM9x（QM9 の平衡構造を計算し直したもの） | 2.957 |

1 eV は約 23 kcal/mol なので、ANI-1x で学習したモデルの誤差は約 11 kcal/mol です。
ANI-1x は元素も理論レベルも同じですが、遷移状態の付近の構造をほとんど含みません。
論文は、ANI-1x で学習したモデルは、遷移状態の付近の複雑な相互作用を学ぶのに十分なデータを持っていない、とまとめています [Schreiner 2022]。
平衡構造だけの QM9x で学習したモデルの誤差は、さらに 1 桁大きくなります。

この例から分かるのは、「同じ元素の、同じ理論レベルのデータで学習した」というだけでは、モデルを使ってよい理由にならないことです。
使いたい構造に似た構造が学習データにあるかどうかを確かめる必要があります。
似た構造があるかどうかを、モデル自身に見積もらせる方法は、[第 10 回](10-cautions.md)で扱います。

### 4.2 元素、電荷、スピンの分布の外

構造だけでなく、元素、電荷、スピン多重度についても同じことが言えます。

- **元素**：第 4 回で見たように、ANI のようなモデルは元素ごとにネットワークを持つので、学習データにない元素はそもそも入力できません。元素ごとのベクトルを学習するモデルでも、学習データにない元素のベクトルは学習されていません。
- **電荷**：入力が原子の種類と位置だけのモデルは、中性分子と陽イオンを区別できません（第 1 回）。SPICE の論文で試されたモデルは、元素と形式電荷の組を別々の「原子の種類」として扱うことで電荷を入れています。論文は、この方法では結合が組み変わると原子の種類が決まらなくなること、形式電荷の割り当てが一通りに決まらない場合があることを、限界として挙げています [Eastman 2023]。
- **スピン多重度**：同じ構造の錯体でも、高スピンと低スピンではエネルギーが違います。スピン多重度を入力に持たないモデルは、この違いを表せません。OMol25 が高スピンと低スピンの両方のデータを含むのは、この違いを学習できるようにするためです [Levine 2025]。

OMol25 の論文は、評価の結果として、中性の有機分子や生体分子より、電解質と金属錯体で誤差が大きい傾向があると報告しています [Levine 2025]。
さらに、電荷やスピン多重度が違う状態の間のエネルギー差（イオン化エネルギー、電子親和力、スピン状態の間のエネルギー差）を予測するのは、金属を含む系では難しいとも書いています [Levine 2025]。
データセットが電荷とスピンを含むようになっても、それを正しく予測できるとは限らないということです。

**ここまでで分かったこと**：モデルは、学習データに似た構造、元素、電荷、スピン状態でしか信用できません。同じ理論レベルのデータで学習していても、構造の分布が違えば誤差は 1 桁以上大きくなることがあります。

## 5. 理論レベルの違うデータを混ぜるとき

データを増やしたいとき、複数のデータセットを合わせて使いたくなります。
しかし、理論レベルの違うデータを混ぜると、同じような構造に対して、少しずつ違う「正解」が与えられることになります。
第 1 回の 5.4 節で注意したように、モデルは食い違う答えを同時にまねようとします。

この問題への対処には、少なくとも 3 つのやり方があります。

1. **同じ理論レベルで新しく計算する**：Transition1x は、ANI-1x と合わせて使えるように、ANI-1x と同じ ωB97X/6-31G(d) を選びました [Schreiner 2022]。
2. **既存のデータセットの構造を計算し直す**：OMol25 は、SPICE や Transition1x などの構造を、自分の理論レベルで計算し直して取り込みました [Levine 2025]。
3. **どの理論レベルの値かをモデルに教える**：理論レベルの違うデータを、目印を付けて 1 つのモデルで学習する方法です。[第 7 回](07-foundation-models.md)で扱う UMA は、この方法を使っています。

自分でモデルを作るときも、既製のモデルを使うときも、学習データの理論レベルが、自分の比べたい値の理論レベルと同じかどうかを確かめてください。
たとえば、OMol25 で学習したモデルの値は、ωB97M-V/def2-TZVPD の値をまねたものです。
B3LYP で求めた値や実験値と比べるときは、その違いも誤差に含まれます。

**ここまでで分かったこと**：理論レベルの違うデータは、そのまま混ぜてはいけません。同じ理論レベルで計算し直すか、どの理論レベルの値かをモデルに教えます。

## まとめ

- データセットは、理論レベル、構造の選び方、元素、電荷とスピン多重度の 4 つの問いで読みます。
- QM9 は平衡構造だけ、ANI-1x はずらした構造、Transition1x は反応の経路、SPICE は薬の分子の MD、OMol25 は元素と電荷とスピンを大きく広げたデータです。
- DFT で学習したモデルは、汎関数の誤差もそのまままねます。
- 学習データにない種類の構造では、同じ理論レベルで学習したモデルでも誤差が大きくなります。
- 理論レベルの違うデータは、そろえてから、または目印を付けてから混ぜます。
