## 1. 外挿に気づきにくい理由

第 6 回で、モデルは学習データに似た構造、元素、電荷、スピン状態でしか信用できないことを見ました。
学習データに似ていない入力について予測することを、外挿（extrapolation）と呼びます。

量子化学計算では、手法が使えない場面で、SCF が収束しない、エネルギーが不自然に跳ぶ、などの「異常の知らせ」が出ることがよくあります。
機械学習ポテンシャルには、そうした知らせがありません。
ニューラルネットワークは、どんな入力に対しても、滑らかに見える数を返します。
そのため、外挿で誤差が大きくなっていても、出力を見ただけでは気づけません。

そこで必要になるのが、「この予測はどれくらい信用できるか」をモデル自身に見積もらせる方法です。

**ここまでで分かったこと**：機械学習ポテンシャルは、学習データの外でも普通に見える数を返します。外挿していることを別の方法で見つける必要があります。

## 2. 不確かさの見積もり：委員会モデル

### 2.1 考え方

最もよく使われる方法は、委員会モデル（committee model）です。
同じ形のモデルを、初期値や学習データの取り方だけを変えて、何個か学習します。
学習データのある領域では、どのモデルもデータに合うように学習されるので、予測はそろいます。
学習データのない領域では、モデルを縛るものがないので、予測がばらばらになりやすくなります。
そこで、モデルの間の予測のばらつきを、不確かさの目安に使います。

Schran らは、委員会の平均はそれぞれのモデルより精度が良く、委員会の意見の不一致が汎化誤差（学習データにない入力での誤差）の目安になると述べています [Schran 2020]。
第 6 回で見た ANI-1x のデータセットも、複数のモデルの予測のばらつきを原子数の平方根で割った量を、データを選ぶ目安に使っています [Smith 2020]。

### 2.2 計算例：H₂ の解離曲線

H₂ の B3LYP/cc-pVDZ のエネルギーで確かめます。
核間距離 0.6〜1.1 Å の 21 点だけで、5 個の小さなニューラルネットワークを学習します。
5 個のモデルは、初期値と、学習データの取り方（同じ数の点を重複を許してランダムに選ぶ、ブートストラップと呼ばれる方法）だけが違います。
それから、学習範囲の内と外で、委員会の予測を DFT の値と比べます。

```python
import numpy as np
from pyscf import gto, dft
from sklearn.neural_network import MLPRegressor

def e_dft(r):
    mol = gto.M(atom=f"H 0 0 0; H 0 0 {r}", basis="cc-pvdz", verbose=0)
    return dft.RKS(mol, xc="b3lyp").run().e_tot * 627.5   # kcal/mol

r_train = np.linspace(0.6, 1.1, 21)          # 学習に使う範囲（Å）
e_train = np.array([e_dft(r) for r in r_train])
e0 = e_train.min()

# 委員会：初期値と学習データの取り方（ブートストラップ）だけが違う 5 個のモデル
rng = np.random.default_rng(0)
models = []
for seed in range(5):
    idx = rng.integers(0, len(r_train), len(r_train))
    m = MLPRegressor(hidden_layer_sizes=(20, 20), activation="tanh",
                     solver="lbfgs", max_iter=5000, random_state=seed)
    m.fit(r_train[idx, None], e_train[idx] - e0)
    models.append(m)

print(" R/Å  学習範囲   DFT の値   委員会の平均   ばらつき   実際の誤差  (kcal/mol)")
for r in [0.5, 0.7, 0.9, 1.1, 1.3, 1.6, 2.0, 2.5]:
    preds = np.array([m.predict([[r]])[0] for m in models])
    true = e_dft(r) - e0
    inside = "内" if 0.6 <= r <= 1.1 else "外"
    print(f"{r:4.1f}    {inside}     {true:7.1f}   {preds.mean():9.1f}   {preds.std():8.1f}"
          f"   {abs(preds.mean() - true):8.1f}")
```

```text
 R/Å  学習範囲   DFT の値   委員会の平均   ばらつき   実際の誤差  (kcal/mol)
 0.5    外        52.7        20.9        3.5       31.8
 0.7    内         1.7         1.7        0.1        0.0
 0.9    内         5.9         5.9        0.0        0.0
 1.1    内        25.3        24.9        0.5        0.4
 1.3    外        47.6        33.9        4.0       13.7
 1.6    外        78.2        35.4        5.0       42.8
 2.0    外       109.7        35.9        5.6       73.8
 2.5    外       135.5        36.3        6.1       99.1
```

「ばらつき」は 5 個の予測の標準偏差です。
エネルギーは、学習データの最小値を 0 として測っています。

### 2.3 結果の読み方

学習範囲の内では、ばらつきは 0.5 kcal/mol 以下で、実際の誤差もそれと同じくらい小さくなっています。
学習範囲の外に出ると、ばらつきは 3.5〜6 kcal/mol に増えます。
つまり、委員会のばらつきは、外挿していることを知らせる目印として働いています。

しかし、ばらつきの値そのものは、実際の誤差よりずっと小さくなっています。
2.5 Å では、ばらつきは 6.1 kcal/mol ですが、実際の誤差は 99 kcal/mol です。
5 個のモデルがそろって同じ方向に間違えている（どれも曲線が平らになっている）からです。
この例から分かるように、委員会のばらつきは「外挿しているかどうか」の目印には使えても、誤差の大きさの見積もりとしてそのまま使えるとは限りません。

もう 1 つ、大事な限界があります。
委員会のばらつきが測るのは、第 1 回の式の「機械学習の誤差」の部分だけです。
5 個のモデルはどれも B3LYP のデータで学習しているので、B3LYP そのものの誤差（第 6 回の 3 節）は、ばらつきにまったく現れません。

**ここまでで分かったこと**：委員会モデルのばらつきは、学習データの外にいることを知らせる目印になります。ただし、誤差の大きさを過小に見積もることがあり、学習データの手法の誤差は測れません。

## 3. 能動学習

### 3.1 考え方

委員会のばらつきが大きい構造は、モデルが知らない構造です。
そうした構造を見つけたら、その構造で量子化学計算を行い、学習データに加えて学習し直せばよいはずです。
このくり返しを能動学習（active learning）と呼びます。
委員会の不一致を使って次に計算する構造を選ぶやり方は、「委員会による問い合わせ」（query by committee）と呼ばれます [Smith 2018]。

手順は次のとおりです。

1. 少ないデータで委員会を学習する。
2. 委員会のモデルで MD などを行い、構造を集める。
3. 委員会のばらつきが決めた値より大きい構造を選ぶ。
4. 選んだ構造で量子化学計算を行い、学習データに加える。
5. 学習し直し、2 に戻る。

### 3.2 報告されている例

**ANI-1x**。
Smith らは、委員会による問い合わせで、有機分子のデータセットを自動的に作りました [Smith 2018]。
要旨によれば、能動学習で作ったモデルは、ランダムに選んだデータで学習した ANI-1 を、その 10% のデータで上回りました [Smith 2018]。
データセットの論文によれば、委員会のモデルで MD を行い、5 ステップごとにばらつきを計算して、決めた値を超えた構造を集めています [Smith 2020]。
ほかに、基準振動に沿ってずらした構造、2 分子の組、二面角を回した構造からも、同じ基準で構造を選んでいます [Smith 2020]。

**水の委員会モデル**。
Schran らは、1 つの参照の第一原理 MD から始めて、能動学習で液体の水、氷のいくつかの相、空気と水の界面まで扱えるモデルを作りました [Schran 2020]。
最終的なモデルの学習に使った参照の計算は 814 個です [Schran 2020]。
この論文は、委員会の不一致を MD の間に監視することも提案しています。

**線形のモデルでの能動学習**。
Podryabinkin と Shapeev は、線形にパラメーター化したポテンシャルについて、D 最適性という統計の基準で構造を選ぶ能動学習を提案しました [Podryabinkin 2017]。
要旨によれば、この方法では、シミュレーションの途中で外挿が起きないようにしながら、ポテンシャルを学習できます [Podryabinkin 2017]。

**ここまでで分かったこと**：能動学習は、委員会のばらつきなどで「モデルが知らない構造」を選び、そこだけ量子化学計算を追加する方法です。少ない計算で、使いたい範囲をおおうデータを作れます。

## 4. スピン状態と電荷

### 4.1 構造だけでは決まらない

第 1 回の 4.4 節で、エネルギーは構造だけでなく、全電荷とスピン多重度にもよることを見ました。
入力が原子の種類と位置だけのモデルは、同じ構造の高スピン状態と低スピン状態を区別できません。
これが最も問題になるのが、遷移金属錯体です。

### 4.2 計算例：[Fe(H₂O)₆]²⁺ のスピン状態

Fe²⁺ に 6 個の水が配位した錯体で、同じ構造の一重項（不対電子 0 個）と五重項（不対電子 4 個）のエネルギー差を計算します。
構造は、Fe–O を 2.10 Å とした八面体で、両方のスピン状態で同じものを使います（構造最適化はしていません）。
基底関数は def2-SVP で、汎関数を 4 つ変えます。
最後の `0.2*HF + 0.8*PBE, PBE` は、PBE の交換の 20% を厳密な交換に置き換えた汎関数です。

一重項は、6 個の d 電子がすべて t2g 軌道（dxy、dyz、dxz）に対になって入った閉殻の状態です。
この状態の SCF は、初期推定によって別の解に落ちやすいので、PBE の閉殻の解を出発点にして、ほかの汎関数の一重項を解きます（理由は表の後で説明します）。

```python
import numpy as np
from pyscf import gto, dft

# [Fe(H2O)6]2+ の八面体構造（Fe-O 2.10 Å。水分子の形は O-H 0.96 Å、H-O-H 104.5°）
def fe_hexaaqua(r_feo=2.10):
    atoms = ["Fe 0 0 0"]
    half = np.radians(104.5 / 2)
    for axis in range(3):
        for sign in (1, -1):
            u = np.zeros(3); u[axis] = sign             # Fe から O への向き
            v = np.zeros(3); v[(axis + 1) % 3] = 1      # 水分子の面の中の向き
            o = r_feo * u
            for s in (1, -1):
                h = o + 0.96 * (np.cos(half) * u + s * np.sin(half) * v)
                atoms.append("H %.4f %.4f %.4f" % tuple(h))
            atoms.append("O %.4f %.4f %.4f" % tuple(o))
    return "; ".join(atoms)

atom = fe_hexaaqua()
ls = gto.M(atom=atom, basis="def2-svp", charge=2, spin=0, verbose=0)   # 一重項
hs = gto.M(atom=atom, basis="def2-svp", charge=2, spin=4, verbose=0)   # 五重項

def d_occ(mol, dm):
    """Fe の 3d 軌道の Mulliken の電子数を、t2g（xy、yz、xz）と eg（z²、x²−y²）に分けて返す"""
    P = dm @ mol.intor("int1e_ovlp")
    occ = {l.split()[-1]: P[i, i] for i, l in enumerate(mol.ao_labels()) if " Fe 3d" in l}
    t2g = occ["3dxy"] + occ["3dyz"] + occ["3dxz"]
    eg = occ["3dz^2"] + occ["3dx2-y2"]
    return t2g, eg

# 一重項の出発点：PBE の閉殻の解（t2g に 6 電子が入った解）
guess = dft.RKS(ls, xc="pbe").density_fit().run().make_rdm1()

print("汎関数                 E(一重項) - E(五重項) /(kcal/mol)   一重項の 3d の電子数（t2g, eg）")
for xc in ["pbe", "tpssh", "b3lyp", "0.2*HF + 0.8*PBE, PBE"]:
    m1 = dft.RKS(ls, xc=xc).density_fit()          # 一重項：閉殻（RKS）
    m1.max_cycle = 200
    m1.kernel(dm0=guess)
    m5 = dft.UKS(hs, xc=xc).density_fit()          # 五重項：開殻（UKS）
    m5.max_cycle = 200
    m5.level_shift = 0.2
    m5.kernel()
    gap = (m1.e_tot - m5.e_tot) * 627.5
    t2g, eg = d_occ(ls, m1.make_rdm1())
    ok = "" if m1.converged and m5.converged else "未収束"
    print(f"{xc:22s} {gap:8.1f}                            {t2g:.2f}, {eg:.2f}  {ok}", flush=True)
```

```text
汎関数                 E(一重項) - E(五重項) /(kcal/mol)   一重項の 3d の電子数（t2g, eg）
pbe                        33.3                            4.53, 0.25  
tpssh                      34.3                            4.58, 0.19  
b3lyp                      34.2                            4.61, 0.17  
0.2*HF + 0.8*PBE, PBE      43.5                            4.60, 0.18
```

表の右の列は、一重項で Fe の 3d 軌道に入った電子の数です。
Mulliken の電子数は基底関数の分け方に依存し、配位子との共有結合の分もあるので、6 にはなりません。
ここで確かめたいのは、電子が t2g に集まり、eg（dz²、dx²−y²）がほぼ空であることです。
4 つの汎関数とも、この意図した一重項に収束しています。

**スピン状態の違い**：どの汎関数でも、同じ構造で、一重項が五重項より 33〜44 kcal/mol 高くなりました。
この差は、化学的精度と呼ばれる目安（1 kcal/mol）[Smith 2020] の 30 倍以上です。
原子の位置がまったく同じでも、スピン状態が違えば、エネルギーはこれだけ違います。

**汎関数への依存**：PBE に厳密な交換を 20% 混ぜると、差は 33.3 から 43.5 kcal/mol に、約 10 kcal/mol 増えました。
厳密な交換を増やすと高スピンが有利になる、という遷移金属錯体でよく知られた傾向です（[遷移金属錯体の計算 第 5 回](../tm-complexes/05-spin-state-energetics.md)）。
一方、B3LYP（厳密な交換 20%）と TPSSh（10%）は、PBE とほぼ同じ値でした。
B3LYP と TPSSh は、厳密な交換の割合だけでなく、残りの交換と相関の部分も PBE と違う汎関数です。
そのため、厳密な交換の割合だけを見て、汎関数どうしの値を比べることはできません。
また、ここでは構造を固定し、小さな基底関数を使った 1 つの錯体での比較なので、どの汎関数が正しいかについては何も言えません。

**SCF の解の確認**：同じ構造でも、一重項の SCF は、間違った解に落ちることがあります。
たとえば `0.2*HF + 0.8*PBE, PBE` で、初期推定を PySCF の標準のままにした RKS は、dyz が空で dz² に電子が入った解に収束しました。
この解では、一重項と五重項の差が 92.5 kcal/mol になりました。
また、標準の初期推定から UKS で解くと、$\langle S^2\rangle$ = 1.41 のスピン対称性の破れた解に収束しました。
どちらも SCF の上では「収束」しています。
エネルギーの値だけでは、意図した状態かどうかは分かりません。
d 軌道の電子数や $\langle S^2\rangle$ を見て、意図した状態に収束したことを確かめてください。
学習データを作るときも、同じ確認が必要です。

### 4.3 研究で使うときの注意

この計算例から、2 つの注意が出てきます。

1 つ目は、モデルの入力です。
スピン多重度を入力に持たないモデルは、この錯体の 2 つの状態に、同じ 1 つのエネルギーしか返せません。
UMA のように全電荷とスピン多重度を入力に持つモデルを使い、正しい値を指定する必要があります（第 7 回）。
ただし、UMA の論文によれば、電荷とスピンの値はそれぞれ別のベクトルで表されていて、学習データにない値には一般化しにくいとされています [Wood 2025]。
また、学習データの OMol25 の論文は、金属を含む系では、スピン状態の間のエネルギー差の予測がとくに難しいと報告しています [Levine 2025]。

2 つ目は、学習データの理論レベルです。
モデルが学習データの汎関数を完璧にまねても、その汎関数の値を再現するだけです（第 6 回）。
OMol25 で学習したモデルは、ωB97M-V の値をまねます [Levine 2025]。
一方、B3LYP のような標準的な汎関数には、多参照性をもつ遷移金属の系の記述に弱点があることが知られている、と DM21 を調べた論文は述べています [Zhao 2024]。
学習データの DFT の値がどれくらい正しいかは、機械学習とは別の問題です。
汎関数のベンチマークや、より精度の高い計算で確かめる必要があります。

電荷についても同じことが言えます。
入力に全電荷を持たないモデルは、中性分子と陽イオンを区別できません。
学習データに含まれる電荷の範囲（第 6 回の表）の外では、全電荷を入力に持つモデルでも信用できません。

**ここまでで分かったこと**：同じ構造でも、スピン状態が違えばエネルギーは数十 kcal/mol 違います。モデルにスピン多重度を正しく入力しても、精度の上限は学習データの汎関数で決まり、金属を含む系では予測そのものも難しいと報告されています。

## 5. 反応の遷移状態

遷移状態は、平衡構造から離れた、結合ができかけ、切れかけの構造です。
平衡構造やその近くの構造を中心に作ったデータセットには、こうした構造があまり含まれません。

第 6 回の 4.1 節で見たように、Transition1x の論文では、ANI-1x で学習したモデルは、遷移状態でのエネルギーの平均絶対誤差が 0.495 eV（約 11 kcal/mol）でした [Schreiner 2022]。
反応の経路の構造で学習したモデルでは、これが 0.075 eV に下がりました [Schreiner 2022]。
第 7 回で見たように、基盤モデルの MACE-MP-0 でも、触媒反応の NEB のエネルギー曲線は定性的にしか合わず、各曲線から 5 つの DFT の計算を加えて追加の学習を行うと、ほとんどの場合で DFT とよく合うようになりました [Batatia 2025]。

これらのことから、機械学習ポテンシャルで求めた遷移状態は、次のように扱うのが安全です。

- 遷移状態の「候補」として使い、障壁の高さの値はそのまま使わない。
- 候補の構造から出発して、DFT で遷移状態の構造を最適化し直す。
- DFT で振動数を計算し、虚数の振動数が 1 つだけであることを確かめる。
- 必要なら、DFT で固有反応座標（IRC）をたどり、その遷移状態が目的の反応物と生成物をつなぐことを確かめる。

**ここまでで分かったこと**：遷移状態の付近は、学習データが少ないことの多い領域です。機械学習ポテンシャルで求めた遷移状態は候補として使い、構造と障壁は DFT で確かめます。

## 6. 長時間の分子動力学での不安定

### 6.1 力の誤差が小さくても安定とは限らない

機械学習ポテンシャルの論文では、テストデータでの力の誤差がよく報告されます。
しかし、Fu らは、力の誤差の小ささが、MD の結果の良さと必ずしも一致しないことを示しました [Fu 2022]。
彼らは、MD の安定性（シミュレーションが物理的にありえない状態に入らずに続くこと）を、機械学習ポテンシャルが改善すべき重要な指標として挙げています [Fu 2022]。

不安定になる理由は、1 節と同じく外挿です。
MD を長く続けると、学習データにほとんどない構造に、いつかたどり着くことがあります。
本文によれば、そうした構造でモデルが極端に大きな力を予測すると、軌跡は物理的でない状態に入ります [Fu 2022]。
たとえば、反応が起きないはずの低い温度で、結合が切れるような状態です。
いったんそうなると、その後の軌跡から求めた物理量には意味がありません。

### 6.2 何を監視するか

長い MD を行うときは、少なくとも次のことを監視してください。

- **結合の長さ**：反応を扱わない MD で、結合が不自然に伸びたり切れたりしていないか。
- **エネルギーの保存**：外部と熱をやり取りしない MD（NVE）で、全エネルギーが一定に保たれているか。モデルの力がエネルギーの微分（保存力）であることが前提です（第 1 回の 3.2 節）。
- **委員会のばらつき**：委員会モデルを使えるなら、軌跡に沿ってばらつきを記録し、大きくなった構造がないか（2 節）。Schran らは、MD の間に委員会の不一致を監視することを提案しています [Schran 2020]。

**ここまでで分かったこと**：力の誤差が小さいモデルでも、長い MD で不安定になることがあります。結合の長さ、エネルギーの保存、委員会のばらつきを監視します。

## 7. 結果を DFT で確かめる手順

ここまでの注意を、研究での確かめの手順にまとめます。

1. **学習データを確かめる**：使うモデルが、どのデータセットで、どの理論レベルで学習したかを調べる。自分の系の元素、電荷、スピン状態、構造の種類（平衡構造か、遷移状態か、溶液か）がその範囲に入っているかを確かめる（第 6 回）。
2. **入力を確かめる**：全電荷、スピン多重度、タスク（どの DFT の設定をまねるか）を入力するモデルでは、正しい値を指定したかを確かめる（第 7 回）。
3. **いくつかの構造で一点計算をする**：モデルで得た大事な構造（安定構造、遷移状態の候補、MD の軌跡から取り出した構造）で、学習データと同じ理論レベルの DFT の一点計算を行い、エネルギーと力を比べる。ここで差が大きければ、モデルはその系で外挿しています。
4. **大事な値は DFT で求め直す**：論文で報告する反応エネルギーや障壁は、DFT で構造を最適化し直し、振動数を確かめたうえで求める（5 節）。
5. **理論レベルを確かめる**：スピン状態の間のエネルギー差のように DFT での扱いが難しい量は、複数の汎関数や、より精度の高い方法で確かめる（4 節）。
6. **足りなければ追加の学習をする**：3 で差が大きかった構造を学習データに加え、モデルを学習し直す（3 節の能動学習、第 7 回のファインチューニング）。

手順 3 と 6 をくり返すことで、モデルを「使う」ことと「確かめる」ことを、同じ流れの中で行えます。

**ここまでで分かったこと**：機械学習ポテンシャルの結果は、学習データの範囲と入力を確かめ、大事な構造で DFT の計算と比べてから使います。

## まとめ

- 機械学習ポテンシャルは、学習データの外でも普通に見える数を返すので、外挿していることを別の方法で見つける必要があります。
- 委員会モデルのばらつきは、外挿の目印になります。ただし、誤差の大きさを過小に見積もることがあり、学習データの手法そのものの誤差は測れません。
- 能動学習は、ばらつきの大きい構造だけを量子化学計算で追加し、少ない計算で必要な範囲をおおうデータを作ります。
- 同じ構造でもスピン状態でエネルギーが大きく違うので、遷移金属錯体ではモデルの入力（スピン多重度）と学習データの理論レベルの両方に注意します。学習データを作る計算でも、SCF が意図した状態に収束したかを、d 軌道の電子数や $\langle S^2\rangle$ で確かめます。遷移状態と長い MD も、外挿が起きやすい場面です。
- 大事な結果は、学習データと同じ理論レベルの DFT で確かめ、必要なら追加の学習をします。
