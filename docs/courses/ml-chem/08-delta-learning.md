    Δ 学習が利用しているのは、安い計算と高い計算の差が、それぞれの値そのものより小さく滑らかなことが多い、という性質です。安い計算が大きな形をとらえ、モデルは細かい修正だけを学べばよいので、少ない高精度のデータで済みます。転移学習は、安い計算の大量のデータで大まかな形を学ばせたあと、少ない高精度のデータで仕上げる方法です。

## 1. Δ 学習の考え方

### 1.1 問題：高精度のデータは少ない

第 1 回と第 6 回で見たように、モデルの精度の上限は、学習データを作った手法の精度で決まります。
上限を上げるには、CCSD(T) のような精度の高い手法でデータを作ればよいのですが、そうした手法は重く、たくさんの構造を計算できません。
そこで、「少ない高精度のデータで、どうやって良いモデルを作るか」が問題になります。

### 1.2 差を学習する

2015 年に Ramakrishnan、Dral、Rupp、von Lilienfeld は、次の考え方を提案しました [Ramakrishnan 2015]。
安い手法（ベースライン）の値はすでに計算できているとして、高い手法（ターゲット）との差だけを機械学習で予測します。

$$
\hat E_\text{ターゲット}(\mathbf R) = E_\text{ベースライン}(\mathbf R) + \hat\Delta(\mathbf R),
\qquad
\Delta(\mathbf R) = E_\text{ターゲット}(\mathbf R) - E_\text{ベースライン}(\mathbf R).
$$

$\mathbf R$ は原子の位置をまとめて書いたもので、ハットはモデルの予測値です。
モデルが学習するのは $\Delta$ だけです。
論文はこれを Δ 機械学習（Δ-machine learning）と呼んでいます。
要旨によれば、この論文では、ベースラインに半経験的手法や HF 法を使い、熱化学的な量や電子相関エネルギーを予測しています [Ramakrishnan 2015]。
たとえば、C₇H₁₀O₂ の最大 1 万 6 千個の異性体の熱化学的な量について、化学的精度に届くことを数値で示しています [Ramakrishnan 2015]。

### 1.3 なぜ差のほうが学習しやすいのか

差を学習するほうが楽になると期待できる理由は、ベースラインが物理の大部分をすでに含んでいるからです。
たとえば HF 法は、全エネルギーの 99% 以上を占める部分（核と電子の引力、電子の運動エネルギー、平均場の反発）を計算します。
残りの電子相関エネルギーは、全エネルギーより値の範囲が狭く、構造によってゆっくり変わることが多いと期待できます。
値の範囲が狭く、ゆっくり変わる関数ほど、少ないデータで精度よく近似できます。

ただし、これは「期待できる」であって、いつも成り立つわけではありません。
ベースラインが定性的に間違う領域（たとえば、HF 法で結合が切れていく領域、第 1 回の 5.1 節）では、差も大きく急に変わるので、学習は難しくなります。

**ここまでで分かったこと**：Δ 学習は、安い手法の値に、機械学習で予測した差を足します。差がゆっくり変わる関数であれば、少ないデータで精度よく学習できます。

## 2. 計算例：HF から MP2 への差を学習する

### 2.1 設定

水分子で確かめます。
2 つの O–H 結合の長さを 0.85〜1.15 Å、H–O–H の角度を 90〜125° の範囲でランダムに選んだ 300 個の構造を作ります。
各構造で、HF と MP2（基底関数は cc-pVDZ）のエネルギーを計算します。

```python
import numpy as np
from pyscf import gto, scf, mp

rng = np.random.default_rng(0)
n = 300
r1 = rng.uniform(0.85, 1.15, n)          # O-H1 の距離（Å）
r2 = rng.uniform(0.85, 1.15, n)          # O-H2 の距離（Å）
th = np.radians(rng.uniform(90, 125, n))  # H-O-H の角度
e_hf, e_mp2 = [], []
for a, b, t in zip(r1, r2, th):
    atom = f"O 0 0 0; H {a} 0 0; H {b*np.cos(t)} {b*np.sin(t)} 0"
    mol = gto.M(atom=atom, basis="cc-pvdz", verbose=0)
    mf = scf.RHF(mol).run()
    e_hf.append(mf.e_tot)
    e_mp2.append(mp.MP2(mf).run().e_tot)
np.savez("water_hf_mp2.npz", r1=r1, r2=r2, th=th, e_hf=e_hf, e_mp2=e_mp2)
```

学習には、カーネルリッジ回帰（kernel ridge regression）を使います。
カーネルリッジ回帰は、学習データの各点からの「近さ」を表す関数（ここではガウス関数）の重ね合わせで、新しい点の値を予測する方法です。
入力（記述子）には、2 つの O–H 距離を小さい順に並べたものと、H–H 距離の 3 つの数を使います。
小さい順に並べるのは、2 つの H 原子を入れ替えても記述子が変わらないようにするためです（第 2 回の置換の不変性）。

最初の 200 個から学習データを取り、最後の 100 個で誤差を測ります。
次の 2 つを比べます。

- **直接学習**：MP2 のエネルギーそのものを学習する。
- **Δ 学習**：MP2 と HF の差を学習し、予測した差を HF のエネルギーに足す。

ガウス関数の幅と正則化の強さは、どちらも学習データの中の交差検証（学習データを分けて、一部で学習し残りで誤差を測ることのくり返し）で選びます。

```python
import numpy as np
from sklearn.kernel_ridge import KernelRidge
from sklearn.model_selection import GridSearchCV

d = np.load("water_hf_mp2.npz")
r1, r2, th = d["r1"], d["r2"], d["th"]
r_hh = np.sqrt(r1**2 + r2**2 - 2 * r1 * r2 * np.cos(th))
# 2 つの H を入れ替えても変わらないように、O-H の距離を小さい順に並べる
X = np.column_stack([np.minimum(r1, r2), np.maximum(r1, r2), r_hh])
kcal = 627.5
e_hf = d["e_hf"] * kcal
e_mp2 = d["e_mp2"] * kcal
delta = e_mp2 - e_hf                      # MP2 の相関エネルギー
print(f"E(MP2) のばらつき（標準偏差） {e_mp2.std():6.2f} kcal/mol")
print(f"Δ = E(MP2)-E(HF) のばらつき   {delta.std():6.2f} kcal/mol")

def fit_predict(Xtr, ytr, Xte):
    grid = {"alpha": [1e-8, 1e-6, 1e-4], "gamma": [1, 3, 10, 30]}
    model = GridSearchCV(KernelRidge(kernel="rbf"), grid, cv=5,
                         scoring="neg_mean_absolute_error")
    model.fit(Xtr, ytr - ytr.mean())
    return model.predict(Xte) + ytr.mean()

test = np.arange(200, 300)                # 最後の 100 個を試験用に取っておく
print(" 学習数   直接学習の誤差   Δ学習の誤差   （平均絶対誤差, kcal/mol）")
for n in [10, 20, 40, 80, 160]:
    train = np.arange(n)
    direct = fit_predict(X[train], e_mp2[train], X[test])
    dl = e_hf[test] + fit_predict(X[train], delta[train], X[test])
    mae_d = np.abs(direct - e_mp2[test]).mean()
    mae_dl = np.abs(dl - e_mp2[test]).mean()
    print(f"{n:5d}     {mae_d:10.4f}      {mae_dl:10.4f}")
```

```text
E(MP2) のばらつき（標準偏差）   6.20 kcal/mol
Δ = E(MP2)-E(HF) のばらつき     2.77 kcal/mol
 学習数   直接学習の誤差   Δ学習の誤差   （平均絶対誤差, kcal/mol）
   10         2.3271          0.1450
   20         0.4975          0.0042
   40         0.0813          0.0020
   80         0.0159          0.0007
  160         0.0041          0.0002
```

### 2.2 結果の読み方

最初の 2 行から、この構造の範囲では、差 $\Delta$（ここでは MP2 の相関エネルギー）のばらつきが、MP2 のエネルギーそのもののばらつきの半分以下であることが分かります。

表を見ると、どの学習数でも、Δ 学習の誤差は直接学習の誤差より 1 桁以上小さくなっています。
言い換えると、同じ誤差に届くのに必要な MP2 の計算が、Δ 学習ではずっと少なくて済みます。
たとえば、直接学習で 160 個使った誤差（0.0041 kcal/mol）に、Δ 学習は 20 個で届いています。
1.3 節で考えたように、相関エネルギーが構造によってゆっくり変わる関数だからです。

ただし、この例は 3 つの自由度しかない小さな問題で、構造の範囲も平衡構造の近くに限っています。
誤差の値そのものは、分子の大きさや構造の範囲によって大きく変わります。
この例から言えるのは、差のほうが学習しやすい場合がある、ということです。

### 2.3 Δ 学習の代償

Δ 学習には代償もあります。
予測のたびに、ベースラインの計算（ここでは HF）が必要です。
そのため、予測の速さは、ベースラインの手法の速さを超えられません。
この例では、HF の計算は MP2 よりは軽いものの、機械学習のモデルの評価よりはずっと重い計算です。

**ここまでで分かったこと**：水分子の例では、HF と MP2 の差を学習すると、MP2 そのものを学習するより、同じデータ数で誤差が 1 桁以上小さくなりました。代わりに、予測のたびにベースラインの計算が必要です。

## 3. 転移学習：ANI-1ccx

### 3.1 考え方

もう 1 つの方法は、転移学習（transfer learning）です。
ある問題で学習したモデルを出発点にして、関連する別の問題のデータで学習し直す方法です。
ANI-1ccx の論文は、次の 2 段階でモデルを作りました [Smith 2019]。

1. 約 500 万個の構造の DFT（ωB97X/6-31G(d)）のデータ（ANI-1x、第 6 回）で学習する。
2. そのうち約 50 万個の構造の CCSD(T)\*/CBS のデータで学習し直す。

2 段階目では、4 層ある隠れ層のうち 2 層を固定し、残りの 2 層だけを学習し直しています [Smith 2019]。
論文は、層を固定するのは、学習し直すパラメーターを減らして、小さい CCSD(T)\*/CBS のデータに過学習するのを避けるためだと説明しています [Smith 2019]。
過学習とは、学習データにだけ合いすぎて、新しいデータで誤差が大きくなることです。

1 段階目で、モデルは、DFT のデータから「分子のエネルギーがおおよそどう決まるか」を学びます。
2 段階目では、DFT と CCSD(T) の違いの部分だけを、少ないデータで直すことになります。
この意味で、転移学習は、Δ 学習と同じく「大部分は安いデータで、差の部分は高いデータで」という考え方の、別の実現の仕方です。

### 3.2 結果

論文は、有機分子の配座の間のエネルギー差のベンチマーク（GDB-10to13）で、次のモデルを比べています [Smith 2019]。

| モデル | 学習の仕方 | 二乗平均平方根偏差（kcal/mol） |
|---|---|---|
| ANI-1ccx | DFT で学習し、CCSD(T)\*/CBS で学習し直す | 2.07 |
| ANI-1ccx-R | CCSD(T)\*/CBS のデータだけで学習 | 2.54 |
| ANI-1x | DFT のデータだけで学習 | 2.79 |

誤差は、CCSD(T)\*/CBS の値と比べたものです。
CCSD(T)\*/CBS のデータだけで学習したモデル（ANI-1ccx-R）は、転移学習のモデルより誤差が 23% 大きくなりました [Smith 2019]。
つまり、同じ CCSD(T)\*/CBS のデータを使っても、DFT のデータで先に学習しておくほうが良い結果になっています。
DFT のデータだけのモデル（ANI-1x）は、さらに誤差が大きくなりました。
第 6 回の 3.2 節で見た反応エネルギーの例（HC7/11）では、この差がもっとはっきり出ていました。

### 3.3 Δ 学習との違い

転移学習で作ったモデルは、予測のときにベースラインの計算を必要としません。
入力は原子の種類と位置だけなので、予測は普通の機械学習ポテンシャルと同じ速さです。
その代わり、ベースラインの物理（たとえば HF 法が正しく含む静電相互作用）に頼ることもできません。
第 3 回で見た局所性の仮定の限界は、そのまま残ります。

**ここまでで分かったこと**：転移学習は、多くの安いデータで学習したモデルを、少ない高いデータで学習し直す方法です。ANI-1ccx では、高いデータだけで学習するより誤差が小さくなりました。

## 4. 半経験的手法との組み合わせ：AIQM1

### 4.1 エネルギーの形

Δ 学習のベースラインを、HF 法よりずっと軽い半経験的手法にすると、予測の速さの代償を小さくできます。
半経験的手法とは、多くの積分を省略し、残りをパラメーターで置き換えた、分子軌道法の安い近似です。
AIQM1（2021 年）は、この組み合わせを、転移学習と一緒に使った方法です [Zheng 2021]。
AIQM1 の全エネルギーは、次の 3 つの和です。

$$
E_\text{AIQM1} = E_\text{SQM} + E_\text{NN} + E_\text{disp}.
$$

- $E_\text{SQM}$：半経験的手法 ODM2 のエネルギー。ただし、ODM2 に元から含まれる D3 の分散力補正を除いたもの（論文では ODM2\* と書いています）。
- $E_\text{NN}$：ANI 型のニューラルネットワークによる補正。原子ごとの寄与の和です（第 3 回）。
- $E_\text{disp}$：D4 という分散力の補正。3 体の項も含みます。

### 4.2 2 段階の学習

ニューラルネットワークの補正 $E_\text{NN}$ は、2 段階で学習されています [Zheng 2021]。

1. **Δ 学習**：ANI-1x の構造について、DFT（ωB97X/def2-TZVPP）と ODM2\* の差を学習する。エネルギーと力の両方を使う。
2. **転移学習**：1 段階目のネットワークの 1 層目と 3 層目の重みを固定し、ANI-1ccx の構造について、CCSD(T)\*/CBS と「ODM2\* + D4」の差を学習し直す。CCSD(T)\*/CBS には力がないので、エネルギーだけを使う。

つまり、AIQM1 は「半経験的手法から DFT への差」をたくさんのデータで学び、それを「半経験的手法から CCSD(T) への差」に、少ないデータで学習し直したものです。
1 節の Δ 学習と、3 節の転移学習の両方を使っています。

### 4.3 何ができて、何ができないか

要旨によれば、AIQM1 は、中性で閉殻の基底状態の分子について、半経験的手法に近い速さで、結合クラスター法に近い精度を目指した方法です [Zheng 2021]。
論文は、イオンや励起状態の性質にも良い精度が出たと報告していますが、ニューラルネットワークの部分はそれらの性質に合わせて学習されていない、とも明記しています [Zheng 2021]。

限界について、論文は次のように書いています [Zheng 2021]。

- 学習データ（ANI-1x と ANI-1ccx）は、H、C、N、O からなる中性で閉殻の小さな分子だけなので、AIQM1 も H、C、N、O の化合物にしか使えない。
- ニューラルネットワークの補正は、分子の電荷や電子状態によらず、同じ構造なら同じ値になる。
- ニューラルネットワークの補正は ANI と同じ限界を持ち、AIQM1 の転移性の高さは、半経験的手法と分散力の補正から来ている。

最後の点は、Δ 学習の利点をよく表しています。
半経験的手法のハミルトニアンは、電荷や長距離の静電相互作用を、近似的ではあっても物理の式として含んでいます。
機械学習の補正が局所的でも、ベースラインがその外の物理を受け持ちます。

**ここまでで分かったこと**：AIQM1 は、半経験的手法をベースラインにした Δ 学習と、CCSD(T)\*/CBS への転移学習を組み合わせた方法です。ベースラインの物理が、機械学習の補正だけでは届かない部分を受け持ちます。

## 5. Δ 学習と転移学習の使い分け

ここまでの内容を表にまとめます。

| | Δ 学習 | 転移学習 |
|---|---|---|
| 学習するもの | 安い手法と高い手法の差 | 高い手法の値（安い手法で学習したモデルから出発） |
| 予測のときに要るもの | ベースラインの計算とモデル | モデルだけ |
| 予測の速さ | ベースラインの手法で決まる | 普通の機械学習ポテンシャルと同じ |
| 長距離の効果や電荷 | ベースラインが含む範囲で扱える | モデルの形で決まる |

どちらを選ぶかは、何に使うかで決まります。
長い MD のように、何百万回も評価する用途では、予測が速い転移学習のモデルが向いています。
少しの構造で、ベースラインでは足りない精度がほしい場合や、ベースラインの物理に頼りたい場合は、Δ 学習が向いています。

どちらの方法でも、第 6 回で見た注意はそのまま当てはまります。
精度の上限は、ターゲットの手法（ここでは CCSD(T)\*/CBS）の精度です。
また、学習データの分布の外、たとえばイオンや開殻の系、学習データにない元素では、予測を信用できません。
Δ 学習では、ベースラインが定性的に間違う領域（1.3 節）でも、予測を信用できません。

**ここまでで分かったこと**：予測の速さが大事なら転移学習、ベースラインの物理に頼りたいなら Δ 学習が向いています。どちらも、ターゲットの手法の精度を超えることはできません。

## まとめ

- Δ 学習は、安い手法の値に、機械学習で予測した「高い手法との差」を足す方法です。
- 差がゆっくり変わる関数であれば、少ない高精度のデータで精度よく学習できます。水分子の HF → MP2 の例では、同じデータ数で誤差が 1 桁以上小さくなりました。
- 転移学習（ANI-1ccx）は、DFT のデータで学習したモデルを、CCSD(T)\*/CBS のデータで学習し直します。予測にベースラインの計算が要りません。
- AIQM1 は、半経験的手法をベースラインにした Δ 学習と転移学習を組み合わせ、ベースラインの物理で転移性を高めています。
