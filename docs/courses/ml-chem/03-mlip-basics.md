# 第 3 回　機械学習ポテンシャルの考え方：原子ごとのエネルギーの和

!!! abstract "この回の道筋"
    多くの機械学習ポテンシャルは、全エネルギーを「原子ごとのエネルギーの和」として表します。この回では、この近似が何を仮定しているのか（局所性）、何をもたらすのか（大きな系への応用、計算時間が原子の数に比例すること）、どこで破れるのか（長距離の静電相互作用）を説明します。最後に、この形のモデルで力をどう計算するかを示し、小さな計算例で確かめます。

    | 節 | 内容 |
    |---|---|
    | 1 | 全エネルギーを原子の寄与に分ける |
    | 2 | 局所性の仮定と、その根拠 |
    | 3 | 力の計算：連鎖律 |
    | 4 | 計算例：小さなクラスターから大きなクラスターへ |
    | 5 | 長距離の静電相互作用の問題 |

    **前に読んでおく回**：[第 1 回](01-what-to-learn.md)、[第 2 回](02-descriptors.md)

!!! tip "物理的なイメージ"
    原子ごとのエネルギーの和という形が仮定しているのは、各原子のエネルギーが、まわりの限られた範囲（カットオフの内側）の原子の配置だけで決まるということです。原子が、自分の近所だけを見て自分のエネルギーを申告し、その合計が全エネルギーになる、というイメージです。近所だけを見るので、大きな系にもそのまま使え、計算時間は原子の数に比例します。そのかわり、遠くの電荷がつくる静電相互作用のように、近所の外から届く効果は表せません。

## 1. 全エネルギーを原子の寄与に分ける

### 1.1 式の形

第 2 回では、原子 $i$ のまわり（カットオフ半径 $R_\mathrm c$ の球の中）の環境を、記述子 $\mathbf G_i$ で表しました。
この記述子を使って、全エネルギーを次の形に書きます。

$$
E = \sum_{i=1}^{N} E_i, \qquad E_i = \varepsilon_{Z_i}(\mathbf G_i).
$$

$E_i$ は原子 $i$ のエネルギー（原子エネルギー）です。
$\varepsilon_{Z}$ は、記述子を受け取って 1 つの数を返す関数で、元素 $Z$ ごとに 1 つ用意します。
たとえば水の系なら、H 用の $\varepsilon_\mathrm H$ と O 用の $\varepsilon_\mathrm O$ の 2 つです。
同じ元素の原子は、すべて同じ関数を使います。

関数 $\varepsilon_Z$ には、ニューラルネットワーク、カーネル法、線形モデルなどを使います。
どれを使うかはモデルによって違いますが、和の形はこの回の話に共通です。
この形は、Behler と Parrinello が 2007 年にニューラルネットワークのポテンシャルとして導入しました [Behler 2007]。

### 1.2 置換の不変性が完成する

第 2 回の計算例で、原子ごとの記述子は、原子の番号を入れ替えると原子と一緒に並べ替わるだけでした。
同じ元素の原子は同じ関数 $\varepsilon_Z$ を使うので、原子エネルギー $E_i$ も原子と一緒に並べ替わるだけです。
和は足す順番によらないので、全エネルギー $E$ は番号の入れ替えで変わりません。
こうして、並進・回転・置換の不変性がすべてそろいます。

### 1.3 原子エネルギーは観測量ではない

注意が 1 つあります。
学習に使うのは全エネルギー $E$（と力）だけで、原子エネルギー $E_i$ の正解はありません。
量子化学計算からも、原子エネルギーは一意には決まりません。
たとえば、ある C 原子のエネルギーを少し上げ、隣の H 原子のエネルギーを同じだけ下げても、全エネルギーは変わりません。
したがって、モデルが出す $E_i$ は、全エネルギーをうまく再現するための中間の量です。
その値に化学的な意味を読み込むときは、慎重になる必要があります。

**ここまでで分かったこと**：全エネルギーを、元素ごとに共通の関数で計算した原子エネルギーの和で表します。和を取ることで、置換の不変性が完成します。

## 2. 局所性の仮定と、その根拠

### 2.1 何を仮定しているか

$E_i$ は、原子 $i$ から $R_\mathrm c$ 以内の原子だけで決まります。
したがって、1 節の形は次の仮定を含んでいます。

> 原子 $i$ から $R_\mathrm c$ より遠くの原子をどう動かしても、$E_i$ は変わらない。

これを局所性（locality）の仮定と呼びます。

### 2.2 なぜ成り立つと期待できるか

この仮定の背景には、Kohn が「近視性」（nearsightedness）と呼んだ電子の性質があります。
化学ポテンシャルを固定したとき、ある点の電子密度のような局所的な性質は、主にその近くの外部ポテンシャルで決まります。
遠くのポテンシャルを変えたときの影響は、距離とともに速く 0 に近づきます [Prodan 2005]。
化学者が「官能基の性質はおおむねその官能基で決まる」と考えて分子を理解しているのは、この性質の表れと見ることができます。

ただし、Prodan と Kohn の議論は、主に電荷を持たない粒子の模型についてのものです。
電荷どうしの相互作用（クーロン相互作用）は、距離の 1 乗に反比例してゆっくり弱まります。
この点は 5 節で扱います。

### 2.3 局所性からの 2 つの帰結

局所性を仮定すると、2 つの大きな利点があります。

**1 つ目は、計算時間が原子の数に比例することです。**
1 つの原子のまわりの球に入る原子の数は、密度が同じなら系の大きさによりません。
そのため、$E_i$ を 1 つ計算する手間は一定で、全体の手間は $N$ に比例します。
通常の量子化学計算の手間が、多くの手法で $N$ の 3 乗以上で増えるのと比べると、大きな違いです。

**2 つ目は、学習したものより大きな系に使えることです。**
大きな系も、原子ごとに見れば、まわりの環境の寄せ集めです。
大きな系に現れる原子環境が、すべて学習データの中に現れていれば、モデルは大きな系のエネルギーも予測できるはずです。
裏を返すと、学習データにない環境が大きな系に現れれば、そこでの予測は外挿になり、信用できません。
4 節の計算例で、この両方を見ます。

和の形には、もう 1 つの性質があります。
2 つの分子 A と B が $R_\mathrm c$ より離れると、互いの原子エネルギーに影響しないので、モデルのエネルギーはちょうど $E(\mathrm A) + E(\mathrm B)$ になります。
量子化学では、無限に離れた A と B のエネルギーが $E(\mathrm A) + E(\mathrm B)$ に等しくなる手法を「サイズ無矛盾」（size consistent）と呼びます。
和の形のモデルは、この条件を作り方の上で自動的に満たします。

ただし、2 つの点に注意してください。
1 つ目に、学習データの手法がサイズ無矛盾でなければ、データとモデルの形が食い違います。
たとえば第 1 回で見た H₂ の RHF は、解離の極限で 2 つの H 原子のエネルギーの和になりません。
2 つ目に、モデルでは「無限に離れたとき」ではなく、「$R_\mathrm c$ だけ離れたとき」に相互作用がちょうど 0 になります。
本当の相互作用は $R_\mathrm c$ の外にも残ることがあり、5 節でその問題を扱います。
なお、量子化学で似た言葉の「サイズ示量性」（size extensivity）は、互いに相互作用しない同じ分子を多数集めた系で、エネルギーが分子の数に比例するかという別の条件です。

**ここまでで分かったこと**：局所性は電子の近視性にもとづく仮定です。この仮定のおかげで、計算時間が原子の数に比例し、学習データと同じ環境からなる大きな系にも使えます。

## 3. 力の計算：連鎖律

第 1 回で見たように、モデルの力はモデルのエネルギーの微分として作ります。
原子 $k$ に働く力は次のとおりです。

$$
\hat{\mathbf F}_k = -\frac{\partial \hat E}{\partial \mathbf R_k}
= -\sum_{i} \frac{\partial E_i}{\partial \mathbf R_k}
= -\sum_{i} \sum_{\alpha} \frac{\partial \varepsilon_{Z_i}}{\partial G_{i\alpha}} \frac{\partial G_{i\alpha}}{\partial \mathbf R_k}.
$$

$G_{i\alpha}$ は記述子 $\mathbf G_i$ の $\alpha$ 番目の成分です。
2 つ目の等号から 3 つ目の等号へは、合成関数の微分（連鎖律）を使いました。

この式には 2 種類の微分が出てきます。

- $\partial \varepsilon_{Z_i} / \partial G_{i\alpha}$：モデルの関数の、入力についての微分です。ニューラルネットワークなら、自動微分で計算できます。
- $\partial G_{i\alpha} / \partial \mathbf R_k$：記述子の、座標についての微分です。第 2 回の対称関数は距離と角度の滑らかな関数なので、解析的に微分できます。

原子 $k$ が原子 $i$ の球の外にあれば、$G_{i\alpha}$ は $\mathbf R_k$ によらないので、$\partial G_{i\alpha} / \partial \mathbf R_k = 0$ です。
したがって、和に効くのは、$k$ 自身と、$k$ から $R_\mathrm c$ 以内にある原子 $i$ だけです。
力の計算も、エネルギーと同じく、手間が原子の数に比例します。

**ここまでで分かったこと**：力は、モデルの関数の微分と記述子の微分の積を、近くの原子について足して求めます。

## 4. 計算例：小さなクラスターから大きなクラスターへ

### 4.1 設定

和の形のモデルが、学習したものより大きな系に使えるかを確かめます。
ここでは、量子化学計算の代わりに、ASE [Larsen 2017] に入っている EMT（effective medium theory）のポテンシャルで Cu のクラスターのエネルギーと力を計算し、それを学習データにします。
EMT は金属のための簡単な経験的ポテンシャルで、何百原子もの計算が一瞬で終わります。
ASE の EMT の実装は、Jacobsen らの 1996 年の論文の定式化に従っています [Jacobsen 1996]。
EMT のエネルギーは原子ごとの項の和の形をしていて、各項はまわりの原子との距離だけで決まります。
ASE（バージョン 3.29.0）の実装では、Cu の場合、約 5.4 Å を境にまわりの原子の寄与を滑らかに弱め、約 5.9 Å より遠くの原子はまったく見ません（5.5 Å での重みは約 0.05 です）。
したがって、カットオフ半径 5.5 Å の和の形のモデルで、ほぼ再現できるはずの相手です。

モデルは、ニューラルネットワークの代わりに、いちばん簡単なものを使います。

- 記述子：第 2 回の動径の対称関数を 8 個（$R_\mathrm s$ = 2.0〜5.0 Å、$\eta$ = 4 Å$^{-2}$、$R_\mathrm c$ = 5.5 Å）。
- 原子エネルギー：$E_i = \mathbf w_1 \cdot \mathbf G_i + \mathbf w_2 \cdot \mathbf G_i^2 + b$。$\mathbf G_i^2$ は成分ごとの 2 乗です。

この形はパラメーター $\mathbf w_1, \mathbf w_2, b$ について線形なので、最小二乗法で一度に決められます。
3 節の連鎖律で、力もパラメーターについて線形な式になります。
そこで、エネルギーと力の両方に合うように、パラメーターを決めます。

学習データは、13 原子、55 原子、147 原子の正二十面体クラスターの原子を、標準偏差 0.1 Å でずらした構造です。
学習に使う大きさを 3 通りに変え、13〜561 原子のクラスター（学習に使っていない構造）で誤差を調べます。

```python
import numpy as np
from ase.cluster import Icosahedron
from ase.calculators.emt import EMT

rng = np.random.default_rng(0)
RC = 5.5                                  # カットオフ半径（Å）
RS = np.linspace(2.0, 5.0, 8)             # ガウス関数の中心（Å）
ETA = 4.0                                 # ガウス関数の幅（Å^-2）

def fc(r):
    return 0.5 * (np.cos(np.pi * r / RC) + 1.0) * (r < RC)

def dfc(r):
    return -0.5 * np.pi / RC * np.sin(np.pi * r / RC) * (r < RC)

def features(R):
    """原子ごとの記述子 G[i, k] と、その座標微分 dG[i, k, a, x] = dG_ik / dR_ax"""
    n = len(R)
    d = R[:, None, :] - R[None, :, :]            # d[i, j] = R_i - R_j
    r = np.linalg.norm(d, axis=-1) + np.eye(n)   # 対角は 0 除算を避けるだけ
    mask = (1 - np.eye(n)) * (r < RC)
    gauss = np.exp(-ETA * (r[..., None] - RS) ** 2)          # (n, n, K)
    g = gauss * fc(r)[..., None] * mask[..., None]
    G = g.sum(axis=1)                                        # (n, K)
    # d g_ijk / d r_ij
    dg = (gauss * (-2 * ETA * (r[..., None] - RS)) * fc(r)[..., None]
          + gauss * dfc(r)[..., None]) * mask[..., None]
    u = d / r[..., None]                                     # dr_ij/dR_i = u_ij
    dG = np.zeros((n, len(RS), n, 3))
    for i in range(n):
        contrib = dg[i][:, :, None] * u[i][:, None, :]       # (j, K, 3)
        dG[i, :, i, :] += contrib.sum(axis=0)                # R_i で微分
        for j in range(n):
            dG[i, :, j, :] -= contrib[j]                     # R_j で微分
    return G, dG

def design(G, dG):
    """E = sum_i [ w1·G_i + w2·G_i^2 + b ] の形。重みについて線形"""
    n = len(G)
    X = np.concatenate([G, G ** 2, np.ones((n, 1))], axis=1)     # 原子ごとの特徴
    dX = np.concatenate([dG, 2 * G[:, :, None, None] * dG,
                         np.zeros((n, 1, n, 3))], axis=1)
    rowE = X.sum(axis=0)                       # エネルギーの行
    rowsF = -dX.sum(axis=0).reshape(X.shape[1], -1).T   # 力の行 (3n, p)
    return rowE, rowsF

def sample(atoms, amp):
    a = atoms.copy()
    a.positions += rng.normal(scale=amp, size=a.positions.shape)
    a.calc = EMT()
    return a.positions.copy(), a.get_potential_energy(), a.get_forces()

# 学習データ：Cu の正二十面体クラスター（13, 55, 147 原子）を少しずつゆがめたもの
data = {n: [sample(Icosahedron("Cu", n), 0.1) for _ in range(m)]
        for n, m in [(2, 60), (3, 10), (4, 4)]}          # n=2,3,4 が 13,55,147 原子
tests = {n: [sample(Icosahedron("Cu", n), 0.1) for _ in range(2)]
         for n in (2, 3, 4, 5, 6)}                       # 13〜561 原子

def fit(train):
    """エネルギーと力の両方に最小二乗で合わせる"""
    A, y = [], []
    for R, E, F in train:
        rowE, rowsF = design(*features(R))
        A += [rowE[None, :], rowsF]
        y += [[E], F.ravel()]
    return np.linalg.lstsq(np.vstack(A), np.concatenate(y), rcond=None)[0]

for used in ([2], [2, 3], [2, 3, 4]):
    w = fit([s for n in used for s in data[n]])
    print("学習に使った大きさ:", [len(data[n][0][0]) for n in used])
    for n, ts in tests.items():
        eE, eF, fF = [], [], []
        for R, E, F in ts:
            rowE, rowsF = design(*features(R))
            eE.append(abs(rowE @ w - E) / len(R))
            eF.append(np.abs((rowsF @ w).reshape(-1, 3) - F).mean())
            fF.append(np.abs(F).mean())
        print(f"  {len(R):3d} 原子: エネルギー誤差 {1000*np.mean(eE):7.1f} meV/原子,"
              f" 力の誤差 {1000*np.mean(eF):5.0f} meV/Å（力の大きさ {1000*np.mean(fF):4.0f} meV/Å）")
```

### 4.2 結果の読み方

結果を読む前に、各クラスターにどんな原子環境があるかを数えておきます。
各原子について、5.5 Å 以内にある他の原子の数を数えます（ずらす前の構造で数えます）。

```python
import numpy as np
from ase.cluster import Icosahedron

for n in range(2, 7):
    R = Icosahedron("Cu", n).positions
    d = np.linalg.norm(R[:, None] - R[None], axis=-1)
    c = (d < 5.5).sum(axis=1) - 1          # 5.5 Å 以内にある他の原子の数
    print(f"{len(R):3d} 原子: まわりの原子の数の最大 {c.max():2d}、54 以上の原子 {(c >= 54).sum():3d} 個")
```

```text

 55 原子: まわりの原子の数の最大 54、54 以上の原子   1 個
147 原子: まわりの原子の数の最大 54、54 以上の原子  13 個
309 原子: まわりの原子の数の最大 56、54 以上の原子  55 個
561 原子: まわりの原子の数の最大 57、54 以上の原子 147 個
```

**13 原子だけで学習したとき**、13 原子のクラスターの誤差は小さいのに、55 原子より大きなクラスターでは誤差が桁違いに大きくなりました。
力の誤差は、力そのものの大きさを超えています。
13 原子のクラスターでは、どの原子のまわりにも 12 個以下の原子しかありません。
大きなクラスターには、まわりに 50 個以上の原子がある原子が現れます。
そのような環境は学習データにないので、モデルは外挿をしていることになります。

**55 原子も加えると**、大きなクラスターでの誤差は大きく下がります。
それでも、147 原子より大きなクラスターでは、誤差が大きくなっていきます。
55 原子のクラスターで、まわりに 54 個の原子がある原子は、中心の 1 個だけです。
まわりが原子で満たされた環境は、学習データの中でごくわずかしかありません。

**147 原子まで加えると**、309 原子と 561 原子のクラスターでも、エネルギーの誤差は 1 原子あたり 10 meV 以下になりました。
147 原子のクラスターには、まわりに 54 個の原子がある原子が 13 個あります。
309 原子と 561 原子のクラスターには、まわりに 56〜57 個の原子がある、学習データにない環境もまだ少しあります。
誤差が 147 原子のときより少し大きいのは、そのためだと考えられます。

この例から分かるのは、和の形のモデルが大きな系に使えるのは、学習データが大きな系の原子環境をすべて含むときだということです。
「何原子の系で学習したか」ではなく、「どんな原子環境が学習データにあるか」が問題なのです。

なお、この簡単なモデルの力の誤差は、55 原子以上のクラスターでは力の大きさの 2〜3 割あります。
EMT も距離だけで決まるので、角度の情報がないことは原因ではありません。
関数の形が 2 次までに限られていること、記述子が 8 個しかないこと、カットオフ半径が EMT の約 5.9 Å より少し短いことが原因と考えられます。
第 4 回と第 5 回では、より表現力の高いモデルを扱います。

**ここまでで分かったこと**：和の形のモデルは、学習データにある原子環境からなる系であれば、学習したものより大きな系に使えます。学習データにない環境が現れると、誤差は大きくなります。

## 5. 長距離の静電相互作用の問題

### 5.1 カットオフ半径の外にも相互作用は残る

局所性の仮定が成り立たない典型は、静電相互作用です。
2 つの水分子を、双極子モーメントが同じ向きに一直線に並ぶように置き、HF/def2-SVP で相互作用エネルギーを計算します。
相互作用エネルギーは、2 分子の全エネルギーから、1 分子のエネルギーの 2 倍を引いたものです。
比較のため、2 つの点双極子の相互作用の式 $-2\mu^2/R^3$（原子単位）の値も並べます。
$\mu$ は 1 分子の HF の双極子モーメント、$R$ は 2 分子の距離です。

```python
import numpy as np
from pyscf import gto, scf

water = [("O", 0.0, 0.0, 0.1173), ("H", 0.0, 0.7572, -0.4692), ("H", 0.0, -0.7572, -0.4692)]

def energy(atoms):
    mol = gto.M(atom=atoms, basis="def2-svp", verbose=0)
    mf = scf.RHF(mol).run(conv_tol=1e-11)
    return mf.e_tot, mf.dip_moment(verbose=0)

e1, mu = energy(water)
mu_au = np.linalg.norm(mu) / 2.541746          # D を原子単位に直す
print(f"単量体の双極子モーメント {np.linalg.norm(mu):.3f} D")
print(" R/Å   相互作用エネルギー/(kcal/mol)   双極子-双極子の式/(kcal/mol)")
for R in [4.0, 6.0, 8.0, 10.0, 12.0]:
    # 2 個目の分子を z 方向に R Å ずらす（双極子が同じ向きに一直線に並ぶ）
    dimer = water + [(s, x, y, z + R) for s, x, y, z in water]
    e2, _ = energy(dimer)
    model = -2 * mu_au**2 / (R / 0.529177) ** 3
    print(f"{R:5.1f}   {(e2 - 2*e1)*627.5:12.3f}               {model*627.5:12.3f}")
```

```text
単量体の双極子モーメント 2.133 D
 R/Å   相互作用エネルギー/(kcal/mol)   双極子-双極子の式/(kcal/mol)
  4.0         -1.997                     -2.047
  6.0         -0.562                     -0.607
  8.0         -0.245                     -0.256

```

6 Å 以上離れても、相互作用エネルギーは 0 になりません。
値は点双極子の式とよく合い、距離の 3 乗に反比例して減っていきます。
カットオフ半径が 5 Å のモデルでは、2 分子が十分に離れると、一方の原子の球に他方の原子が入らなくなります。
そのとき、モデルの相互作用エネルギーはちょうど 0 になり、この相互作用を表せません。

1 組の分子では、6 Å での −0.56 kcal/mol は小さく見えるかもしれません。
しかし、液体や結晶では、1 つの分子のまわりの遠い分子の数は、距離の 2 乗に比例して増えます。
イオンを含む系では、相互作用は距離の 1 乗に反比例するので、さらにゆっくりとしか弱まりません。
Unke らの総説は、電荷を持たず双極子モーメントも大きくない分子では、カットオフの外の相互作用は多くの場合問題にならないが、電荷と双極子の相互作用のような強い長距離の寄与があると大きな誤差になりうる、とまとめています [Unke 2021]。

### 5.2 カットオフ半径を大きくすればよいか

カットオフ半径を大きくすれば、もっと遠くまで見えます。
しかし、2 節で見たように、球の中の原子の数は $R_\mathrm c^3$ に比例して増え、計算は重くなります。
また、記述子が遠くの多くの原子の影響を受けるようになるので、同じ精度を得るのに必要なデータも増えると指摘されています [Unke 2021]。

### 5.3 物理の式を組み込む

そこで、エネルギーを 2 つに分ける方法がよく使われます。

$$
E = \underbrace{\sum_i E_i}_{\text{短距離：機械学習}} + \underbrace{\frac{1}{2}\sum_{i \neq j} \frac{q_i q_j}{R_{ij}}}_{\text{長距離：クーロンの式}} .
$$

$q_i$ は原子 $i$ の部分電荷で、これも原子環境から機械学習で予測します（式は原子単位で、短い距離で発散しないようにする工夫は省いています）。
部分電荷そのものは観測量ではないので、量子化学計算の双極子モーメントを再現するように学習する方法などが使われています [Unke 2021]。
分散力についても、DFT で使われる経験的な分散力補正（D3 など）の項を足すことがよくあります [Unke 2021]。

ただし、部分電荷を原子環境から予測する方法にも限界があります。
分子の一方の端の構造を変えると、電荷が遠くまで移動することがあります。
このような非局所的な電荷移動は、各原子のまわりだけを見て電荷を決める方法では表せません。
Ko らは、原子ごとの電気陰性度を機械学習で予測し、系全体で電荷の釣り合いを解いて電荷を決める方法（第 4 世代の高次元ニューラルネットワークポテンシャル）を提案しました [Ko 2021]。
また、Grisafi と Ceriotti は、遠くの原子の情報を、静電ポテンシャルと同じ距離依存性を持つ原子ごとの記述子として取り込む方法を提案しました [Grisafi 2019]。

長距離の相互作用をどう扱うかは、今も研究が続いている問題です。
機械学習ポテンシャルを使うときは、そのモデルが長距離の項を含むのか、含むならどう扱うのかを確かめる必要があります。

**ここまでで分かったこと**：静電相互作用はカットオフ半径の外にも残ります。部分電荷とクーロンの式を組み込む方法や、系全体で電荷を決める方法が提案されています。

## まとめ

- 多くの機械学習ポテンシャルは、全エネルギーを、元素ごとに共通の関数で計算した原子エネルギーの和で表します。原子エネルギーそのものは観測量ではありません。
- この形は局所性を仮定しています。その結果、計算時間が原子の数に比例し、学習データにある原子環境からなる大きな系にも使えます。
- 力は、モデルの関数の微分と記述子の微分を連鎖律で組み合わせて求めます。
- 静電相互作用はカットオフ半径の外にも残るので、物理の式を組み込むなどの工夫が必要です。
