# 遷移金属錯体の計算

遷移金属錯体の電子状態と、触媒反応の計算を学びます。
量子化学・計算化学から見て、なぜ遷移金属が難しいのか、どの方法がどこまで信頼できるのかを、最近のベンチマーク研究とあわせて解説します。
前提：「量子化学の理論」の第 I 部と第 IV 部。
